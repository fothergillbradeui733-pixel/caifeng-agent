## 1. 核心公式

用以下公式检验项目是否能持续：

> 具体且不公的开篇剥夺 + 被错误估值的资产/能力 + 有限制的重复故事引擎 + 主角主动兑现 + 不同资源层级的阶段对手 + 可见的身份/事业升级 + 终局价值重定义

一句话故事必须同时回答：谁、被夺走什么、获得什么机会、靠什么行动、最终成为什么。只写“获得系统一路打脸”不算完整命题。

同时准备两个标题：

- **主剧名**：短、有记忆点、承载核心物件或关系。
- **平台长标题**：直接说开局损失、异常能力和最大上升结果，但不泄露终局全部答案。

## 2. 主角与情绪账

主角必须有两条并行弧：

- **外部阶梯**：从求生、立足、获得资格，到建立团队、规则和长期事业。
- **内部误区**：从错误信念走向新原则，例如“吃亏能换爱”转为“有边界地负责”。

让观众同时追四本账：

| 账 | 内容 | 典型可见物 |
|:--|:--|:--|
| 物质账 | 欠款、现金、订单、资产、产量 | 账本、钱、合同、机器、粮食 |
| 道德账 | 谁伤害、谁逃避、谁承担 | 契约、证词、归还物、赔偿 |
| 关系账 | 信任、边界、共同决策 | 借条、签字、钥匙、岗位 |
| 信息账 | 谁知道秘密、证据何时公开 | 弧纹、档案、试验、证人 |

每个阶段至少结算其中两本账，不能只增长财富数字。

## 3. 故事引擎规则

金手指、重生、空间、奇物、身份或专业优势都要写成规则表：

| 项 | 必须回答 |
|:--|:--|
| 功能 | 它具体能改变什么？ |
| 触发 | 什么行为或条件使其生效？ |
| 输入/输出 | 消耗什么，得到什么？ |
| 反馈 | 主角怎样知道成功、失败或余量？ |
| 代价 | 越大收益带来什么更大成本？ |
| 禁区 | 什么绝对不能做？ |
| 缺陷 | 错误输入会怎样原样放大？ |
| 知识边界 | 它不能替主角知道什么？ |
| 升级 | 何时扩大能力，为什么只发生有限次数？ |
| 退出 | 终局如何退居背景、失效或被制度替代？ |

规则必须通过动作逐步发现，不能让角色突然念出说明书。能力的最佳用途是提供稀缺起点或样件；判断、检验、安装、经营、医疗、法律与责任由人完成。

中段必须安排一次由主角误用规则造成的真实失败。失败至少造成时间、金钱、信用、关系或身体风险之一，并用3至5集完成承认、赔偿、修复和制度升级。

## 4. 阶段反派

反派按资源升级，不按嗓门升级：

| 层级 | 资源 | 常用动作 | 主角新的取胜能力 |
|:--|:--|:--|:--|
| 家庭/亲密 | 情感、名分、财产习惯 | 逼迫牺牲、划清界限、道德绑架 | 立边界、留下书面证据 |
| 小生意 | 货源、价格、地头关系 | 垄断、压价、栽赃 | 专业、账证、客户信用 |
| 行业/机构 | 资格、审批、库存、舆论 | 卡程序、封渠道、设门槛 | 合法路径、团队、公开验证 |
| 终局规则战 | 署名、安全、档案、组织身份 | 抢成果、改记录、嫁祸 | 制度、证据链、第三方认证 |

每个反派都要有合理利益、有效手段、学习能力和失败原因。阶段结束后立即由胜利结果引出更高层问题，避免停顿。

## 5. 全季架构

集数可配置。60集推荐六阶段：

| 阶段 | 集段 | 任务 | 必须发生的升级 |
|:--|:--|:--|:--|
| 开局承诺 | 1-5 | 完成剥夺、首次触发、核心盟友站队 | 第一次小兑现和大钩子 |
| 生存立足 | 6-15 | 把优势变成可追溯收入 | 第一反派结算、获得牌照/渠道 |
| 责任建制 | 16-30 | 遭遇误用或扩张失败并修复 | 从个人好心升级为质量/合同制度 |
| 团队放大 | 31-40 | 面对公共危机或更大任务 | 从能人变成团队组织者 |
| 自主事业 | 41-50 | 建造属于自己的产品/组织 | 终局反派夺取成果或制造事故 |
| 证据夺名 | 51-60 | 用长期积累完成规则战 | 奇遇退场，制度与关系闭环 |

若是30集，把每阶段压成5集；若是80集，增加新的能力台阶和对手资源，不把同一阶段拉长。

节奏门槛：

- 每集兑现一个小结果。
- 每2至3集发生一次明显反转或能力验证。
- 每5集完成一个小单元。
- 每10集改变一次身份、资产、规则或对手等级。
- 中点必须改变主角对故事引擎或自身责任的理解。

## 6. 单集结构

每集约2分钟时，优先2至4场，使用六拍：

1. **0至2秒硬画面**：动作、损失、异常结果或具体羞辱。
2. **6秒内利益说明**：金额、期限、生命、身份、订单或证据。
3. **主动选择**：主角提出并执行方案，不只挨骂。
4. **有效阻力**：对手、规则、技术或关系让方案付出代价。
5. **可见验证**：机器启动、票据对上、钱款交割、检验、证人或第三方裁定。
6. **行动型尾钩**：新证据出现、事故发生、期限开始、对手已经动手。

尾钩不得只是“你给我等着”、角色震惊或下集预告。好尾钩会改变下一集的第一项行动。

开集接上集时，先处理“未了动作”，不要把上一集已完成事件重新演一遍。每集小闭环完成后再抬升问题：

> 本集压力 → 主动行动 → 验证 → 小兑现 → 胜利产生新责任/危险

## 7. 关系与和解

伴侣或搭档必须拥有独立能力、资源、判断和否决权。至少在一个关键节点让其纠正主角，而不是只提供嫁妆、情绪支持或夸赞。

主要关系冲突优先来自：来源担保、风险边界、共同财产、职责分工、秘密知情权、错误责任。避免靠出轨、恶毒情敌和反复误会拖集数，除非用户明确选择该类型。

家人悔改使用四步：

1. 现实代价让其无法继续自欺。
2. 公开承认自己的具体责任，不甩锅。
3. 归还、赔偿、照顾、作证或承担风险。
4. 长期守住新边界，不索取股份、职位或无条件兜底。

主角可以救急和原谅，但不替赌债、懒惰或再次越界买单。

## 8. 中段失败与终局

中段失败要证明主题，不只制造虐点。主角的长处应在过量使用后变成错误，例如：太愿意帮人导致跳过检验，太相信记忆导致忽略变化，太重亲情导致证据缺失。

终局需要回收：

- 开篇剥夺的物件或契约
- 主角最初的错误信念
- 核心规则的限制和退出
- 伴侣/团队的共同贡献
- 可悔改角色的行动成本
- 阶段积累的票据、制度或证据
- 一个普通动作证明主角已不依赖奇遇

终局胜利不应只是“更有钱”。让主角成为能制定边界、训练他人、承担质量、分配收益或建立规则的人。

## 9. 去重复压力测试

逐集大纲锁定前完成：

1. 给每集写唯一“核心看点”和唯一“尾钩”。完全相同则重构。
2. 标注每集主要解决手段：专业、账证、谈判、救援、团队、制度、关系、试验。连续三集相同则换挡。
3. 标注每集可见物质变化。没有变化的集通常只是过场。
4. 删除任意一集，若前后因果仍完整，合并或重写该集。
5. 检查反派是否连续只用辱骂或举报；给其新的资源动作。
6. 检查主角是否每次都靠奇遇；至少一半关键胜利必须由人和长期积累完成。
7. 检查前10集是否已经兑现剧名承诺，后10集是否已转向主题终局而非继续刷小打脸。
