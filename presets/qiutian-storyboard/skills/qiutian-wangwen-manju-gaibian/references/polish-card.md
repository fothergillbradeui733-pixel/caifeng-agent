# 精修检查单（polish-card）—— 仅 ~polish 时读

> 对象：已PASS的单集或区间（`~polish N` / `~polish N-M`）。写作规则与转化公式见 `write-card.md` 的 `WR-CAUSAL/WR-SHOOT`。

**第一遍｜逐字对照原著（读取本集剧情点对应的原著章节原文）**：
1. **因果触发**：本集每个"反应拍"（追问/震惊/决定）向上找触发拍——触发被压掉的，按原著补回（见 `WR-CAUSAL`）
2. **名台词/名场面**：对照剧情点「必保清单」与「原著内容」摘录逐条找锚点；被压掉且无〔取舍〕登记的，补回或补登记
3. **梗归属与顺序**：笑点/对话的归属人与 setup→punchline 顺序与原著逐一比对（对话/喜剧题材必做，其余题材抽查名场面）
4. **有意取舍确认**：确属压缩取舍的，在 plot-map 对应条目登记〔取舍〕，不改剧本

**保真免费模式专项遍｜取舍账闭环（仅 progress 已启用时执行）**：
1. 读取 `fidelity-free-mode.md`，逐条对照本集「保真锚点／改编处理」与原著原文
2. 所有非 `原序保留` 项核对出处、理由、去向与不变项；剧本出现未登记的移位/并场/删减时先补判定，不得用精修名义静默扩大改编
3. 核对开场无擅自未来闪前、集尾未切断完整呈现单元、强化未新增剧情功能
4. 触及核心结果/动机/关系转折/揭晓顺序/具名角色合并/结局时，停止修改并提交用户决定；获批后在剧情点与 `audit-log.md` 双处登记

**第二遍｜全△/※可拍抽查（逐条聋哑人测试；按需读取 `WR-SHOOT` 与 `visual-style-ref.md`）**：
- 重点抓**词表外**语义违规：无生命物传情绪（"剑传来快乐"）、数值 tell（"修为越高伤越重"）、概述说话（"听说/说了此事"）、台词嵌△、内心意图（"本想劝她"）
- 修法按 `WR-SHOOT`：并置演出/动作化/转台词/转OS/删

**修改后流程**：
1. 先运行quality scope Plan。只改格式/时间/台账/视觉时按计划定点复检；精修导致正文语义变化时必须FULL
2. 执行`goal-runner Next`当前阶段给出的机检/quality命令，FAIL清零后只把生成的checker brief交给checker
3. 接缝回校：重新核对上一集末两场、末场快照、未了动作、原著时间锚与实体状态在本集的接续；若回改上一集core/continuity/timeline或末场状态，重建本集上下文包并重做接缝检查
4. 台账复核：进入台账阶段后执行`goal-runner Next`给出的台账命令；按新版剧本核对更新本集判断项，并满足 `FAIL=0`、`TODO=0`、`LEDGER-RECEIPT-PASS`
5. 视觉交接最终签发：进入视觉签发阶段后执行`goal-runner Next`给出的视觉命令；待所有剧本写入结束后恢复READY并通过Validate、Index和Status，增量或全量范围服从Next
6. 精修记录写项目根 `audit-log.md`（一集一条：改了什么·为什么），**不写入 progress.md**
