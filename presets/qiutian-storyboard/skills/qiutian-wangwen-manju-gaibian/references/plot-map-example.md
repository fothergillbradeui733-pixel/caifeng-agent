## 批次 1：第1章 ~ 第6章

### 【剧情01】林家豪宅的公开羞辱
- **原著章节**：第1章 ~ 第2章
- **原著锚点**：第1章｜「就带了这么个东西回来？」
- **原著内容**：林母当众嫌弃陈锋穷酸，林浩天逼他下跪，赵倩提议林小雨改嫁赵家公子；陈锋沉默承受羞辱，无名指黑色戒指微微泛光。
- **行动主体/承受主体**：林母、林浩天、赵倩｜陈锋、林小雨
- **信息流**：事件前林家众人只把陈锋当作落魄女婿 → 通过公开羞辱与陈锋隐忍反应 → 事件后众人仍不知其真实身份，观众只获得黑色戒指异常的伏笔
- **冲突类型**：打脸复仇
- **冲突强度**：A
- **情绪钩子**：🔨压力蓄积
- **必保清单**：「就带了这么个东西回来？」｜林母｜公开羞辱起点；黑色戒指微微泛光｜陈锋｜隐藏身份伏笔
- **改编处理**：原序保留｜不改变公开羞辱的触发、承受关系和黑色戒指伏笔
- **归属集数**：EP-01
- **状态**：待用

### 【剧情02】神秘来电——龙主时候到了
- **原著章节**：第2章
- **原著锚点**：第2章｜手机屏幕「龙主，时候到了」
- **原著内容**：嘲笑达到最高点时，陈锋手机收到「龙主，时候到了」；他看完短信抬头冷笑，宣告三年期满。
- **行动主体/承受主体**：未具名发信人、陈锋｜陈锋、在场林家众人
- **信息流**：事件前观众与林家众人都不知道陈锋的隐藏身份 → 通过短信特写与陈锋回应 → 事件后观众知道他是「龙主」，在场众人仍未获知
- **冲突类型**：悬念揭示
- **冲突强度**：S
- **情绪钩子**：❓悬念牵引
- **必保清单**：「三年期满。该还的，一分不少。」｜陈锋｜看完短信抬头后的第一句；嘲笑最高潮→手机震动→抬头冷笑｜陈锋｜三拍顺序
- **改编处理**：并场｜与剧情01同归EP-01，不改变揭晓边界、名台词归属和三拍顺序
- **归属集数**：EP-01
- **状态**：待用

### 【剧情03】龙组副手当众跪拜
- **原著章节**：第3章
- **原著锚点**：第3章｜「龙主，三年之约已满，请您回归。」
- **原著内容**：十二名黑衣人从豪宅大门外列队入厅，为首副手向陈锋单膝跪地并宣告龙主回归；全场死寂，林家众人出现雪茄掉地、腿软等反应。
- **行动主体/承受主体**：龙组副手、黑衣人｜陈锋、林家众人
- **信息流**：事件前林家众人不知道陈锋身份 → 通过副手当众跪拜并宣告「龙主」 → 事件后林家全员确认陈锋的隐藏身份
- **冲突类型**：身份碾压
- **冲突强度**：S
- **情绪钩子**：💥爽点释放
- **必保清单**：「龙主，三年之约已满，请您回归。」｜龙组副手｜跪拜后的身份宣告；雪茄掉地、林母腿软｜林家众人｜身份揭晓反应
- **改编处理**：原序保留｜保留列队入厅、跪拜宣告和群像反应的因果顺序
- **可拍性**：预计3拍｜同框17人｜换景1次｜黑衣人群像
- **归属集数**：EP-02
- **状态**：待用

### 【剧情04】赵家上门威胁——新势力登场
- **原著章节**：第5章 ~ 第6章
- **原著锚点**：第5章｜烫金信纸「三日之内，交出林小雨」
- **原著内容**：赵家管家送来威胁信，要求三日内交出林小雨，否则与林家同归于尽；陈锋看完只淡淡一笑，表示赵家排不上号。
- **行动主体/承受主体**：赵家管家（代表赵家）｜陈锋、林小雨
- **信息流**：事件前陈锋与林小雨不知道赵家的明确要求 → 通过威胁信 → 事件后两人知道「三日内交人」期限及赵家敌意
- **冲突类型**：悬念揭示
- **冲突强度**：B
- **情绪钩子**：🔨压力蓄积
- **必保清单**：「三日之内，交出林小雨」｜赵家威胁信｜期限原话；「赵家？排不上号。」｜陈锋｜看信后的态度落点
- **改编处理**：压缩｜压缩送信过程，保留三日期限、威胁结果和陈锋回应
- **归属集数**：EP-03
- **状态**：待用
