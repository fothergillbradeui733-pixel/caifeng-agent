# 视觉化写作示例库（visual-style-ref）

> 本文件仅提供正反对照与转化示范，不新增规则；权威规则为 `write-card.md` 的 `WR-SHOOT`。
> **定点查询**：写作中拿不准「拍不到→可拍」的转化写法时查对应节；质检被退回维度5（台词）/维度7（可拍性）类问题时查对应节。

## 一、△ 正误示范

**正确示范**：
```
△ （特写）陈锋的手指缓缓收紧，将合同纸角压出折痕。
```

**错误示范**（把心理、安静、复杂情绪都塞进 △）：
```
△ 陈锋坐在椅子上，桌子上有一份合同，房间里很安静，
  窗外是城市的夜景，他的心情很复杂，既有愤怒又有
  悲伤，还有一丝不甘……
```

## 二、「拍不到」六类对照表

镜头是聋哑人——闻不到、尝不到、读不懂内心、看不见过去、拍不出「没发生的事」。

| 拍不到的内容 | 反面（错误写进 △） | 正面（转化后可拍 / 或入内心OS） |
|------|------|------|
| **① 动机·心理·原因** | △ 张三内心极度紧张，怕被发现偷了项链。 | △ 张三端着咖啡，嘴角僵硬地笑。<br>△ （特写）他的手指剧烈颤抖，咖啡洒在手背上，他却毫无察觉。<br>或：【内心OS·张三】别抖……千万别让他们看出来。 |
| **② 抽象概念·时间跨度** | △ 他们在一起长达五年之久。 | △ 两人一起吹灭第 5 根生日蜡烛。<br>△ 墙上日历一页页翻过，窗外树叶由绿转枯又冰雪消融。 |
| **③ 嗅觉·味觉·触觉** | △ 房间里弥漫着刺鼻的霉味。 | △ 王五刚迈进一只脚，脸色骤变，立刻用衣袖捂住口鼻，剧烈干呕。 |
| **④ 身份·社会关系**（无外部特征时） | △ 张三是这家公司的幕后大老板。 | △ 秘书快步迎上，深深鞠躬，双手递上文件：「张总。」 |
| **⑤ 过去发生的前情** | △ 张三昨晚熬夜看了一宿球赛，现在很困。 | △ 张三顶着浓重的黑眼圈，哈欠连天，一头栽倒在办公桌上。 |
| **⑥ 否定句（没做某事）** | △ 赵六装作不认识初恋女友。 | △ 初恋女友红着眼眶从赵六身边走过。<br>△ 赵六死死盯着电梯按钮，把它按得咔咔响，坚决不转头。 |

## 三、五条转化公式示范

核心秘诀：**把内心变成动作，把过去变成道具，把看不见的变成反应。** 每当写出「觉得 / 认为 / 回想起 / 其实是 / 一股……味」这类词，立刻问自己：**「他要让观众看出来，现在得摸什么、看哪里、脸怎么抽动一下？」**

1. **心理·动机（对应①）→ 下意识身体动作 / 道具互动**
   - 紧张 → △ 手指颤抖，咖啡洒出却浑然不觉。
2. **过去·背景·身份（对应④⑤）→ 细节特写 / 仪式感动作 / 道具**
   - 退伍特种兵 → △ 他剥苹果，刀锋极快，果皮整条不断；脱外套时后背露出一道狰狞刀疤。
3. **嗅觉·味觉·触觉（对应③）→ 夸张表情 / 身体本能反应**
   - 汤很咸（味觉）→ △ 他喝了一口，眉头瞬间锁死，扭头吐了出来。
   - 一股恶臭（嗅觉）→ △ 他刚推门就猛地后仰，反手死死捂住口鼻。
4. **抽象时间跨度（对应②）→ 经典转场 / 标志性道具交替**
   - 三年艰难岁月 → △ 桌上日历一页页翻过；墙角泡面桶从几个堆成一座小山。
5. **否定句（对应⑥）→ 对比动作 / 视线焦点**
   - 没带手机 → △ 他摸遍所有口袋，一脸焦虑。

## 四、两类漏网写法对照表

### A.「没察觉 / 没注意到」类 → 并置演出

| ❌ 写进 △ | ✅ 并置演出（两句都可拍） |
|------|------|
| △ 江月白看得入神，浑然不觉一道阴影自身后逼近。 | △ 江月白捧书出神，指尖顺着书页一行行划下。<br>△ 她身后，一道身影正悄然逼近、伸出手来。 |
| △ 他毫无防备，没听见门被推开。 | △ 他戴着耳机，跟着节拍晃头，背对着门。<br>△ 门，被人无声地推开一道缝。 |

### B. 全知旁白 / 替旁人写心声 → 可拍动作 ＋ 窃语台词

| ❌ 写进 △（替旁人叙述） | ✅ 可拍动作 ＋ 窃语台词 |
|------|------|
| △ 周围弟子交头接耳——又是那个杂役"八十一"。 | △ 周围弟子循声望来，交头接耳、朝她指指点点。<br>围观弟子<br>（低声讥笑）<br>瞧，又是那个杂役"八十一"…… |
| △ 众人窃窃私语，都说这小子是装的。 | △ 人群一阵骚动，几人交换眼色、撇嘴冷笑。<br>路人甲<br>（嗤）<br>装，接着装。 |

## 五、角色语言分层与情绪烈度参考

### 角色语言分层

| 角色类型 | 说话特征 | 示例 |
|---------|---------|------|
| 大佬/强者 | 简短、命令式、不解释 | 「处理掉。」「我的人，谁动谁死。」 |
| 弱势角色 | 犹豫、解释多、反问 | 「我……我只是想说……」 |
| 反派嚣张 | 轻蔑、嘲讽、优越感 | 「就你？也配？」 |
| 市井角色 | 口头禅多、情绪外露 | 「我跟你说，这事儿没完！」 |
| 古代权贵 | 文雅有力、少现代词 | 「本王的事，轮不到你置喙。」 |

### 情绪烈度与台词密度（动态漫口径，单句硬限 35 字）

| 情绪烈度 | 台词长度 | 示例 |
|---------|---------|------|
| 极度愤怒/震惊 | 1-5字 | 「滚。」「你——」 |
| 强烈对抗 | 5-15字 | 「你有几条命，再说一遍试试。」 |
| 日常对话 | 15-25字 | 「这件事我来处理，你不用管。」 |
| 信息铺垫 | 20-30字 | 「三年前那份合同，是你父亲亲手签的。」 |

任一档超 35 字必须**拆双句**（如「三年前那份合同——」／「是你父亲亲手签的。」），不得单句硬塞。

## 六、六类禁忌台词示例表

| 类型 | 错误示例 | 修正方向 |
|------|---------|---------|
| 自我剖析式 | 「我知道自己很脆弱，但我不能倒下。」 | 不放进**台词**。改为动作（△ 他咬牙，重新站直）；若必须保留心声，转为 `【内心OS·角色】我不能倒。` |
| 旁白解说式 | 「你以为你赢了，其实你已经输了。」 | 必须有具体所指，不能悬空 |
| 文学抒情式 | 「爱情如同一把双刃剑。」 | 删除，改为具体事件 |
| 过度礼貌式 | 「非常感谢您的帮助，铭记于心。」 | 「这份情，我记着。」 |
| 信息过载式 | 一句话塞入时间地点人物原因 | 拆成2-3句或改为 △ |
| 画面复读式 | △ 已演示「他掏出匕首」，台词却复述「你竟然掏出了匕首！」 | 台词不得单纯复述紧邻 △ 已演示的事实——必须携带**增量**（态度/代价/决策/关系），否则删 |

## 七、场景衔接正反示例

**❌ 硬切（剧情跳脱）**：
```
（上一场：出租屋，陈锋答应去家宴）
————直接切————
场次 X-2：内  林家豪宅  日
△ 林母拍桌：「配不配站在这？」
        ↑ 观众懵：什么时候到的？谁在哪？怎么就吵起来了？
```

**✅ 加桥（④内心OS搭桥 ＋ ②字幕定位 ＋ ③落地开场）**：
```
（上一场结尾：【内心OS·陈锋】林家……三年了，也该轮到我回去了。）  ← ④内心OS搭桥

【字幕：次日 / 林家豪宅】                                      ← ②字幕定位

场次 X-2：内  林家豪宅·客厅  日
△ （全景）陈锋和林小雨刚踏进客厅，满堂宾客的目光齐刷刷扫过他洗白的T恤。  ← 落地：谁/在哪/什么场合一拍说清
△ 林母放下茶杯，皮笑肉不笑。
```
