# 独立语义审查契约

确定性机检全绿 ≠ 内容通过。交付前必须做一次独立语义审查。

## 角色分离

- **Planner**：出导演编排计划，不写终稿正文；
- **Writer**：按锁定的计划和台账写正文；
- **机检**：结构、字段、编号、时长、禁项；
- **Critic**：新鲜上下文；只报有证据的问题；
- **Fixer**：只拿到被认可的问题清单和允许范围，只改失败 Block 与必要邻居；
- **用户**：裁决审美偏好与源歧义。

Writer 不得在同一上下文里给自己验收。Critic 可以是同模型，但必须在**新鲜独立上下文**执行；样片、关键集或高危歧义优先用第二个强模型。

## Critic 输入（只给这些，不倾倒全季）

- 本集需要的源证据摘录；
- 锁定的项目基调与导演计划;
- 当前 Block + 必要的前后邻居 Block；
- 空间/角色状态/场景/核心道具台账；
- 简短评审细则。

## 审查维度

1. 源忠实：必需节拍与台词全覆盖，无编造情节/关系/动机/道具/揭示；
2. Block 边界与观看入口逻辑；
3. 镜头动机与"取景主体-画面中心"一致；
4. 动作/台词时长可行性；
5. 表演与情绪连续；
6. 空间、轴线、动作阶段、画外连续；
7. 核心道具的外观、持有者、位置、交接、状态；
8. 场景布局与导演调度一致；
9. 基调锁定逐字复用，无漂移（含服装词、地域词回潮）；
10. 相邻 Block 桥接质量。

## Issue Schema

```json
{
  "issueId": "SB-E03-B07-02",
  "severity": "high",
  "blockId": "EP03-B07",
  "shotId": "S03",
  "dimension": "prop_continuity",
  "sourceEvidence": ["EP03-SC04-L18"],
  "problem": "精确、可观察的矛盾。",
  "requiredCorrection": "恢复合同所需的结果。",
  "allowedScope": ["EP03-B07", "EP03-B08"],
  "confidence": 0.96
}
```

无法引用源/锁定计划/台账证据的问题一律拒收，除非明确标注为审美建议。

## 修复策略

1. 先验证 critic 问题再修；
2. 只改 `allowedScope`；
3. 重算受影响的结束/开始状态与资产绑定；
4. 重跑确定性 + 语义两道门；
5. 自动修复最多两轮；
6. 仍有高危未决项上报用户。

## 覆盖强度

- 两集样片：导演 critic + 源/连续性 critic；
- 常规集：确定性机检 + 一个语义 critic；
- 关键/高复杂度集：加第二个语义 critic；
- 全季：跨集角色、场景、核心道具、未闭合事实、基调审计；
- 批量生产期间至少 10% 常规集用第二 critic 抽检。
