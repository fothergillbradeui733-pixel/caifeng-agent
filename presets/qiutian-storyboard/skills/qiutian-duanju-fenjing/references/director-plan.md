# 导演编排与 Block 拆分决策（阶段二核心）

写正文前必须完成本文件的全部产出。导演编排不是事后总结，是**预决策**。

## 一、整集导演计划（Episode Director Plan）

逐集内部完成，精华写进交付文件头的「## 导演编排总纲」：

| 字段 | 内容 |
|---|---|
| 场景顺序 | 场次清单＋每场的戏剧功能（开场钩子/铺垫/爆发/收束） |
| 节拍表 | 每个 beat 的功能（钩子/铺垫/递进/爆发/爽点/反转/收束/下一钩）＋观众收益（获得什么信息/情绪） |
| 观看入口 | 每场从什么进入：脸/动作/反应/道具/环境/屏幕/人群压力 |
| 核心道具流 | 承重道具（信物/证据/金手指物）的状态流转：谁持有→在哪→何时交接 |
| Block 边界草案 | 先定边界再写正文（见第三节四原则） |
| 预定剪辑 | 每个 Block 尾镜→下一 Block 首镜的剪辑意图（对接 seam-audit） |

### 「导演编排总纲」交付格式（文件头必填章节）

```text
## 导演编排总纲
- 全集镜头弧线：{压迫段} → {转折段} → {爆发段} → {收束+钩子}
- Block N 主动作「{一句话命名}」：{为什么这么拍，镜头如何服务剧情}
```

## 二、Block skeleton（每 Block 一份，内部台账）

```text
Block N：
  戏剧任务：本段必须完成的剧情推进
  观看入口：脸/动作/反应/道具/环境/屏幕/人群
  场景与时段：@地点（日/夜）
  镜头可见主体：竖屏 1–3 / 横屏 2–4 个重点（3D 横屏 2–5）
  画外连续状态：在场未入画者的位置/动作
  主节拍：一个主动作（一条弧线主轴）
  必需台词：S级原文 + A级压缩稿
  关键反应：谁的反应是本段落点
  时长估算：台词朗读 + 动作实算（目标 10–14s）
  预期镜头数：2–4 镜
  生成复杂度：低/中/高 + 原因 + 处理策略
```

### 生成复杂度台账（内部，不进交付正文）

复杂度原因是拆 Block、改调度、加参考、重点审查的依据：

- 多人群像调度（>3 个清晰身份焦点）
- 复杂身体接触（摔/抱/扭打）
- 精确道具交接（递/接/换手）
- 长可读屏显文字
- 格斗/追逐运动
- 多主体遮挡关系

处理策略四选一：**拆 Block / 改调度（减焦点、换景别）/ 增加参考锚点 / 升级审查深度**。

**铁律：难度只影响"怎么生成"，不影响"写不写"。** 剧本要求的剧情、台词、动作、特殊运镜一律保留；高复杂度只做实现层优化（拆更细、换机位、加锚点、预留抽卡），绝不因 AI 难生成而删剧情、降手法或改成简单镜头。

## 三、Block 拆分四原则（15 秒是硬上限，不是拆分依据）

> 铁律：**禁止到 15 秒机械切**。拆分是导演决策，按以下四原则依序判断。

### 原则① 按剧情拆（第一优先）

好切点：

- 一个物理动作完成；
- 一句承重台词落地，下一拍是反应；
- 揭示改变了观众认知；
- 角色到达新空间锚点并停住；
- 明确的场景/时间跳跃。

坏切点（禁止）：

- 起立/转身/递接/坐下的半途；
- 复杂身体接触进行中；
- 承重台词说到一半；
- 攻防动作未解决；
- 人物与镜头运动都没有稳定可读相位。

### 原则② 按镜头拆

- 一个 Block 一条镜头主动作（一条弧线主轴）。**镜头弧线需要换挡时开新 Block**：压迫（缓推）→ 释放（缓拉）、见证（固定）→ 揭示（横摇）、跟随（跟移）→ 定格（固定）。
- 上一 Block 以缓推压迫收尾，下一 Block 用固定承接或缓拉释放——不许无缘由重复同一种推进。
- 镜头数服务节奏：2 镜=对照，3 镜=递进，4 镜=完整小叙事；不为凑数加镜。

### 原则③ 按 AI 生成难度拆

写正文前用复杂度台账预扫每个候选 Block。**难度是拆分粒度与实现策略的依据，不是删减内容的理由**：

- 命中高复杂度原因（见上表）→ 把该 Block **拆得更细**（一个动作相位/一个焦点一段）、**增加参考锚点**、预留抽卡次数；
- 剧情必须一镜完成的 → 保留原样，在台账标记并交付后重点审查，配尾帧衔接/多段拼接策略；
- 判断标准：这个 Block 交给视频模型，一次能生成的概率高吗？主体会不会互相污染？动作会不会糊？
- **绝不**因难度高而删除剧情、替换剧本要求的特殊运镜，或把戏剧手法降级成普通镜头——那是生成端的问题，用抽卡和衔接手段解决。

### 原则④ 按衔接拆（预演接缝）

- 切点定下后，**预演** Block N 尾镜 → Block N+1 首镜的接缝（走 seam-audit.md 的 smooth-seam gate）：
  - 上一结束状态能否自然成为下一开始状态？
  - 跨缝能否做到恰好一个有动机的镜头变量 + ≥2 个桥锚点？
- 接缝过不去 → **移动边界**（提前或推后一个节拍），而不是硬切；
- 实在无法平滑 → 换场/换时间重建（全景重新建场），这是合法出路。

### 决策记录（每个边界一行，内部）

```text
边界 N|N+1：
  拆分依据：①剧情/{②镜头换挡/③难度/④接缝}
  切点：{动作完成/台词落点/…}
  接缝预演：过 / 移边界至… / 重建场
```

## 四、时长

- 目标 10–14s；15s 仅当台词/动作完整性要求时用满；不为填满加无意义停顿。
- 台词朗读估算：字数÷语速（正常4.5字/秒、急6、深情沉重3.2）+ 留白0.4–0.8s。
