# 项目基调锁定合同（style-lock）

项目开工、换题材/时代/风格，或缺锁定基调时，使用本合同。

## 两个独立选择

```text
题材导演习惯（内部指导编排）：家庭伦理 / 复仇爽剧 / 甜宠 / 年代写实 / 悬疑…
影像基调行（公开逐字复用）：一句话锁定
```

题材习惯只影响编排（节奏、表演压力、揭示策略），**不写进公开基调行**。

## 基调行格式（用户拍板口径）

```text
{影像风格} + {题材质感：默认"年代剧质感"，按题材换} + {色调：默认暖黄，可按场次换冷/青/低饱和} + 光影/材质特征
```

**铁律：**
- 基调行**不写地域词**（不写"华中农村""八零年代农村"等）。地域感靠场景、道具、习俗、人物关系呈现。
- 不写人物服装。
- 不写口号式品质词（"精美绝伦"之类）。
- 光影默认明亮通透；压迫感靠人物关系与站位，不靠暗光。确需暗场（夜屋单光源等）在基调里写"灯光明亮柔和、屋内通透"兜底。

## 选择流程

1. 从**完整剧本覆盖地图**匹配，不只看开头样本；
2. 给 2–3 个候选，各一句话理由；
3. 用户确认或修改后锁定；
4. 冻结基调行原文、适用集数范围；
5. 每个 Block 的「视频整体基调」**逐字复用**锁定行（可加场次级光影补充，如"黄昏斜阳""夜屋单光源"）；
6. 用户要求换风格 → 新版本，标记受影响的已交付分镜需复审；禁止静默覆写锁定。

## 示例

```text
写实电影感、年代剧质感、暖黄色调、真实肤质与物理光影、胶片颗粒
```

```text
真人写实电影感、当代都市质感、冷暖对比色调、利落硬光、克制景深
```

这些是示例不是默认。禁止字符串匹配式套用。

## 音色锁定（与基调同等地位）

项目包若有权威音色锁定文件（如 `character-cards.md`「角色音色锁定」），分镜音色行**必须逐字抄锁定值**，禁止自写音色描述。无锁定文件时按五维模板自拟，以"标准普通话。"收尾。

音色里的"带轻微XX乡音"是角色属性，不是地域词——保留。
