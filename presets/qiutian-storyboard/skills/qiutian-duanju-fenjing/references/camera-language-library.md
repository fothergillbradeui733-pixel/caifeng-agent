# 导演镜头语言库

> 只承载"术语 → 戏剧动机 → 适用情绪 → 写法示范"，不承载格式规则。术语名与动机留在导演编排说明里，不进交付正文；正文只写可渲染画面。焦段数值不进正文（AI 不需要焦段参数，用景深效果描述代替）。

## 使用铁律

1. 每个镜头语言术语必须回答三问：此刻为什么用它？它服务什么情绪/关系/权力？去掉它损失什么？答不出就不写。
2. 禁止无动机堆砌：不许"一会固定、一会缓慢"地轮换术语找变化。相邻镜头换景别/运镜，必须是因为有了新的戏剧节拍。
3. 编排顺序固定：戏剧任务 → 情绪曲线 → 镜头弧线（推=压迫 / 拉=释放 / 固定=见证）→ 再在情绪拐点选景深/焦段/光影/构图/速度。术语是最后一步，不是第一步。
4. 每个 Block 主打 1–2 种手法，手法是盐不是主菜。优先级：景深/焦点 > 光影 > 构图 > 速度 > 特殊镜头。
5. 术语要写成可渲染画面（"背景里的男人渐渐虚化"），不写成术语注释（"运用焦点转移手法表现……"）。

## 一、景深与焦点（最叙事的一类）

| 手法 | 戏剧动机 | 适用情绪 | 写法示范 |
|---|---|---|---|
| 浅景深 | 把主体从环境隔离：此刻世界只剩这一人/一事 | 沉浸、告白、对峙、孤独 | 背景虚化，只有她的脸是清晰的 |
| 全景深 | 人与环境同框共存：命运感、无处可逃 | 压迫、宏大叙事、群像 | 前景人物与远处人群同样清晰 |
| 焦点转移 A→B | 注意力/情感/权力从一方移到另一方，比切镜更连续 | 察觉、视线转向、答案落在听者身上 | 焦点从她的脸滑到他垂在身侧的手 |
| 虚→实 | 看清、真相浮现、记忆苏醒 | 悬疑揭晓、重逢 | 门口的人影从模糊里渐渐清晰 |
| 实→虚 | 失去、离去、意识涣散 | 告别、昏迷、放手 | 他的背影渐渐沉进虚化里 |
| 长焦压缩 | 人贴得近心却远；窥视感；人群中孤立 | 偷听、疏离、跟踪 | 两人的身影压在同一平面，前后人群虚化 |
| 前景遮挡虚化 | 观众是局外人、窥视、隔着一层 | 偷听、不安、秘密 | 透过虚化的门缝拍进去 |

## 二、焦段（性格速查，数值不进正文）

| 焦段 | 性格 | 戏剧用途 |
|---|---|---|
| 16–24mm 广角 | 透视扩张、边缘变形 | 环境压迫、癫狂、梦魇、喜剧夸张 |
| 35mm | 人眼视角 | 纪实感、日常、跟随 |
| 50mm 标准 | 中性、无态度 | 客观叙述、群像 |
| 85mm 人像 | 压缩柔和、背景融化 | 情绪特写、对话、亲密 |
| 105mm 微距 | 极近质感 | 泪珠、指尖、道具揭示 |
| 135–200mm 长焦 | 空间压缩、主体从环境剥离 | 孤立、窥视、追逐、人群中两人疏离 |

## 七、速度

| 手法 | 戏剧动机 | 适用 |
|---|---|---|
| 慢动作（升格） | 瞬间太重、要观众看清 | 心动、打击、泪落、回眸 |
| 速度突变 正常→升格 | 日常被情绪击中 | 一见钟情、震惊、噩耗 |
| 速度突变 升格→正常 | 梦醒、回到现实 | 恍惚结束、爆发后余波 |
| 刻意保持实时（不用升格） | 现实残酷、不给预兆、不给同情 | 毫无预兆的泪、猝死、冷漠分手——升格会预告眼泪，实时更疼 |
| 延时 | 时间无情、命运不等 | 等待成空、四季更替 |

## 八、蒙太奇与剪辑

> Block 交付形态下：Block 内剪辑 = 镜头行编排；Block 间剪辑 = 起始空间状态 + 首镜衔接。下表术语用于 Block 内镜头组设计与转场 Block 设计，不改变交付格式。

| 手法 | 戏剧动机 | 适用 |
|---|---|---|
| 交叉剪辑 | 双线逼近、倒计时压力 | 营救、追逐、同时欺骗 |
| 匹配剪辑 | 两物同命、视觉押韵 | 梦→现实、过去→现在 |
| 跳切 | 情绪崩坏、时间碎裂 | 崩溃、失眠、执念 |
| L切/J切（声先/画先行） | 情绪延续、下一场提前渗透 | 回忆带出、噩梦前奏 |
| 硬切反差 | 反差、幻觉撕碎 | 喜剧→悲剧、梦醒 |
| 叠化/淡入淡出 | 时间柔化流逝、章节感 | 回忆、时间流逝、收尾 |

## 九、镜头弧线设计法（导演编排顺序）

1. 先定 Block 情绪曲线：如"压迫→压迫→释放"或"积累→爆发→定格"。
2. 给曲线配镜头动作：压迫=缓推/固定/景别收紧；释放=缓拉/固定定格；爆发=甩镜/急推/景别跳档；定格=固定/升格。
3. 景深/焦段/光影/构图变化放在情绪拐点上：情绪转弯=焦点移动、光线变化、景别放开。
4. 一个 Block 一条镜头主动作（一条弧线主轴），其余手法都是主轴上的变化。
5. 跨 Block 看弧线：上一 Block 以缓推压迫收尾，下一 Block 用固定承接或缓拉释放，不许无缘由重复推进。

## 十、跨场空间关系与 POV 导演法（EP-94 复盘沉淀）

> 铁律：两个角色之间存在物理距离（隔街/隔房间/隔人群）时，禁止把他们写进同一个近景/特写同框——AI 会无视距离硬凑同框，造成站位穿帮。距离必须先拍出来，再谈对视。

| 手法 | 戏剧动机 | 适用 | 写法示范 |
|---|---|---|---|
| POV 三镜头勾视线 | 发现/被凝视的标准语法：先拍"目光顿住"，再反打"被看的对象"，最后回到发现者反应——悬念靠距离不靠台词 | 隔街对视、人群中发现、偷看被撞破 | ①他目光飘向街对面，忽然顿住（近景）→ ②他的视角：街对面那人直勾勾盯着他，中间隔着往来人流（全景，强调一街之隔）→ ③他蹙眉收回视线（近景） |
| 距离的物理化 | 两人之间的物理距离 = 关系距离；距离不变则关系不变，距离缩短必须有动机 | 暗恋、对峙、和解 | 一街之隔=暗恋未开口；过街走到面前一步远=孤注一掷 |
| 跨场移动必须写 A→B | 后续同框对话/肢体接触（拍肩）必须有物理依据；剧本若跳过移动，导演要补：起点→过程→终点 | 隔街→当面对话 | 他在街对面攥了攥拳，穿过往来人流，快步走到陆以北面前一步远处站定 |
| 非参与者不入画 | 喜剧群戏/私密对话的 Block 里，不该在场的角色不进出场、不进镜头、不进结束站位——写了就会生成错位穿帮 | 群像喜剧、密谈、旁观者尚未入场 | 陈卫只在"发现"与"变调"Block 入画，兄弟说笑段落完全不出现 |
| 同一机位重复利用（距离递进） | 第二次用同样的凝视机位时推近一档/收紧一档，暗示执念加深、威胁逼近 | 跟踪、暗恋、压迫升级 | Block 1 街对面全景固定 → Block 5 同一视角改缓推："距离仿佛又近了一分" |
| 指代禁用 | 人物一律用 @资产名 指代；"黑脸汉子""那个男人"等模糊文学表达会让 AI 随机生成外貌，造成角色错乱 | 全部 | ❌"一张肌肤偏黑的脸" ✅ @陈卫（外观以资产参考图为准） |

## 十一、特殊运镜与转场百科（应用场景＋AI 生成难度）

> 来源：Wikipedia 电影技法词条（Whip pan / Dolly zoom / Crane shot / Steadicam / Snorricam / Film transition / Rack focus / Bullet time）＋本管线实测。
> **AI 生成难度**：★=稳定可出；★★=偶发瑕疵需抽卡；★★★=高抽卡/易穿帮，需要更细的拆分与参考锚点；★★★★=AI 生成不稳定，需要抽卡/尾帧辅助/多段拼接等手段保效果。
> **铁律：难度只影响"怎么实现"，不影响"用不用"。** 剧本和导演判断要用的特殊运镜/转场，绝不因 AI 难度高而删掉或降级成普通镜头——戏剧效果优先。难度高的手法要的是更周全的实现策略（拆细、加参考锚点、抽卡预算、尾帧衔接），不是放弃。

### A. 特殊运镜

| 手法 | 戏剧动机 | 应用场景 | 写法示范 | AI难度 |
|---|---|---|---|---|
| 摇臂升／降（crane） | 升起=俯瞰命运、仪式感、超脱；降落=从上帝视角坠入压迫 | 章节开场、死亡、大场面收尾、从全景压到主角 | 镜头从屋顶缓缓降落，越过人群，落在 @秦川 肩头 | ★★★（主体易飘） |
| 稳定器跟拍长镜头（steadicam） | 陪伴、同行、沉浸代入、命运同路 | 行走对话、入场、追逐、穿越空间 | 镜头贴着 @林秋禾 的肩后跟拍，随她穿过集市，一路不停 | ★★★（长镜头易断/主体漂移） |
| Snorricam 身体挂载镜头 | 世界摇晃而主体不动=迷失、醉酒、崩溃、被裹挟 | 醉酒、惊恐奔逃、精神失控、被人群推着走 | 镜头固定在 @陈彪 胸前随他踉跄，他的脸始终清晰，四周街景剧烈晃动 | ★★★★（AI 极难稳定） |
| 甩镜转场（whip pan） | 注意力急转、硬过渡、时间流逝、 frenetic 节奏 | 场景硬切、双地点快速衔接、喜剧节奏点 | 镜头猛地甩向街尾，画面拉成模糊光带，甩定已是瓜摊前 | ★★（甩的过程糊=预期） |
| 希区柯克变焦（dolly zoom） | 世界骤然眩晕、认知崩塌、 vertigo | 震惊、背叛发觉、恐惧顶点 | @沈冰 的脸大小不变，背景老街急速压缩逼近，一阵眩晕 | ★★★★（主体+背景反向缩放 AI 难控） |
| 360° 环绕（orbit） | 情绪顶点、世界只剩彼此 | 告白、重逢、爆发瞬间 | 镜头围着相拥的两人缓缓绕半圈，背景渐次流转 | ★★★（环绕易变形） |
| 焦点转移（rack focus） | 注意力/权力从一方移到另一方，比切镜更连续 | 察觉、视线转向、答案落在听者身上 | 焦点从 @秦川 的脸滑到 @何秀梅 垂在身侧攥紧的手 | ★★（见第一节，AI 较稳） |
| 子弹时间（bullet time） | 瞬间凝固、选择的重量 | 打击、告别凝视、决定瞬间 | 时间凝住，@罗春生 飞起的药箱停在半空，镜头缓缓绕过 | ★★★★（多机位环绕 AI 难） |
| 弧线环绕推近（arc push-in） | 缓慢锁定、宿命逼近 | 对峙、锁定目标、心理压迫 | 镜头沿弧线一边绕一边推近 @秦志远，越收越紧 | ★★★ |

### B. 特殊转场（Block 间衔接用）

> 转场不是"换镜头"，是叙事标点。选转场先问：此处情绪/时空要断还是要连？

| 转场 | 戏剧动机 | 应用场景 | 落地写法 | AI难度 |
|---|---|---|---|---|
| 硬切（cut） | 干脆、不给缓冲、制造冲击 | 默认；冲突、反转、爆点 | 直接下一 Block 首镜，靠 smooth-seam gate 保证连续 | ★ |
| 甩镜转场（whip pan） | 注意力急转、时间压缩 | 场景硬切、喜剧节奏 | 上一尾镜甩成光带 → 下一首镜从甩定起 | ★★ |
| 匹配剪辑（match cut） | 两物同命、视觉押韵 | 梦→现实、过去→现在、主题呼应 | 上一尾镜 @破罐 罐口的圆 → 下一首镜同构的圆（如满月/搪瓷缸口） | ★★★（两镜形状须严格对位） |
| 叠化（dissolve） | 时间柔化流逝、章节感 | 回忆、时间流逝、收尾 | 上一尾镜渐隐叠入下一首镜，画面短暂重叠 | ★★ |
| 淡入淡出（fade） | 段落感、呼吸、情绪沉淀 | 集尾、大段落结束 | 末镜渐暗卡黑 / 开镜自黑渐亮 | ★ |
| L切／J切（声画先行） | 情绪延续、下一场提前渗透 | 回忆带出、噩梦前奏、对白跨场 | 下一场的环境声/台词先在上一尾镜出现（或反之） | ★★（靠音频规范落地） |
| 遮挡转场（wipe by object） | 物理遮挡自然过渡 | 人物/物体掠过镜头 | 上一尾镜一人从镜头前走过遮黑 → 下一首镜从遮黑后展开 | ★★（用前景遮挡，AI 较稳） |
| 跳切（jump cut） | 情绪崩坏、时间碎裂、焦躁 | 崩溃、失眠、执念、等待 | 同机位多次跳切，人物状态突变 | ★★ |

### C. 特殊视点

### 使用守则

1. **难度是执行参考，不是删减理由**：命中 ★★★ 及以上的手法，若剧本/导演判断需要用，**必须保留**，并匹配对应实现策略——拆成更细的 Block 降低单段复杂度、增加参考锚点、预留抽卡次数、用尾帧素材衔接、多段生成后拼接。只有当手法本身损害剧情表达时才换方案，绝不因"AI 难生成"而降级。
2. **特殊转场要有桥锚**：用匹配剪辑/遮挡转场时，仍须满足 seam-audit.md 的 ≥2 个视觉桥锚点，不许只靠"看着炫"。
3. **一集特殊运镜 ≤2 处**：特殊镜头是高光盐，铺满就失效。
4. **正文只写可渲染画面**：术语名（crane/dolly zoom）留在导演编排说明，正文写"镜头从屋顶降落""背景压缩逼近"。
5. **角度揉正文**：以上手法的角度变化（俯/仰/主观）按铁律写进镜头正文，不进括号。
