# 资产索引合同（转分镜的资产绑定唯一口径）

写任何分镜正文之前，必须先完成资产索引。本合同改编自秋天资产联动规范（qiutian asset-linkage），适配 Block 分镜交付形态。

## 1. 事实源与优先级

裁决顺序（高→低）：

1. **剧本**（剧情事实源）
2. **资产索引 / character-cards / 资产库**（视觉事实源）
3. **交接文件**（handoff / source-facts，仅作资产名与别名补充）
4. **分镜正文**（只消费上面三层，不发明）

读取顺序：先读索引/角色卡全文（通常很小），需要具体卡片细节时再按卡名定位读资产库对应区块；**禁止整读大型资产库**。

**音色与资产同源**：角色音色锁定表与角色状态索引通常在同一个权威文件（如 `character-cards.md`）。音色行必须逐字抄锁定值——八零 EP-01 曾自写音色导致返工，此条为铁律。

## 2. 资产覆盖预检（写正文前必做）

按剧本逐场提取入画对象，对照索引做四类覆盖核对：

| 类别 | 核对内容 | 未覆盖时 |
|---|---|---|
| 角色 | 说话者、近景/特写主体、关键动作者 → 索引有无 @资产 + 本集适用状态 | 登记缺口 |
| 场景 | 每个场次地点 → 索引有无场景卡 | 登记缺口 |
| 道具 | 剧情承重道具（信物、证据、金手指物）→ 有无道具卡 | 登记缺口 |
| 音色 | 每个说话者 → 有无音色锁定 | 无锁定→五维自拟，报用户 |

预检输出一张「本集资产索引表」写进分镜文件头部（`## 本集使用人物/资产索引`），列：人物@名、场景@名、道具@名、逐镜内联说明。

## 3. @引用规则

### 角色（出场行与正文）

- `👤 出场` 行只列**镜头可见**的重点角色，一律 `@资产名_状态名`（按状态索引取本集适用状态）。
- 挂 @ 的门槛：清晰口型对白、近景/特写焦点、关键动作/反应、连续性状态变化——满足任一。
- 纯背景、被遮挡、画外发声者不挂 @、不进缺口清单，用聚合描述（"数名村民在后景虚焦"）。
- 单 Block 视觉角色主体建议：竖屏 1–3 个、横屏 2–4 个（3D 横屏 2–5）；群像承担关键反应时写 `{群体名}=@{群像卡}` 占 1 个名额。
- 人物一律 @资产名指代；禁止"那个男人""黑脸汉子"等模糊文学表达（AI 会随机生成外貌）。

### 道具（正文内联，不设道具行）

- 分镜**不输出**任何"道具参考"行。
- 库内道具实际入画时，在镜头正文**每次出现**该道具名称都直接写 `@规范道具名`；台词引号内纯提及不加 @。
- 资产名匹配按长度从长到短，先长名后短名，避免短资产名污染长资产名。
- 一次性剧情道具（无卡）在文件头资产索引里注明"剧情道具，随镜头叙事呈现"。

### 场景

- `📍 场景` 行用 `@场景卡名（日/夜）`；无场景卡的地点按交接文件规则处理并在文件头注明。

## 4. 多状态与状态时间线

- 多状态角色（换装期、病中/康复、婚礼装等）必须挂 `@资产名_状态名`，状态名以角色卡「角色状态索引」的生效范围为准（如：秦川 EP01-04=@秦川_分家装，EP06 起=@秦川_机修装）。
- 集首状态核对：上一集集尾快照 × 本集开场 × 状态索引区间，三方对账；差异必须绑定切换锚（剧本明确的换装/换态事件）。
- 状态切换无剧本证据时，默认沿用上一状态；禁止为画面好看私自换状态。

## 5. 缺口清单

缺失的重点资产不得悬空，也不得在分镜里临时编文生图卡。登记：

```text
| 缺口名 | 类型 | 首次Block | 剧本证据 | 正文@名 |
```

分镜正文先按唯一规范 `@资产名` 占位（同一缺口只允许一种命名），然后把缺口清单交给上游建卡流程（qiutian-shijue-zichan-tishici 或项目资产库维护者）；建好卡后回收核对。最终仍悬空的 @ 视为 FAIL。

## 6. 借用与化名

视觉是库内资产、剧情只用化名时，文件头写：

```text
借用登记：{化名}=@{库资产}（借用·{依据}）
```

出场行照常写化名=@库资产。

## 7. 跨集状态对账（每集开工第一步）

1. 读上一集「集尾空间快照」：逐角色姿态/位置/持物/伤势/去向、未闭合事实、直续/跳跃判定。
2. 与状态索引核对：有没有跨集切换锚（如婚礼集换婚礼装）。
3. 直续集：开场 Block 的 🧭 起始空间状态 = 上集快照承接；跳跃集：重新建场并写明依据。

## 8. 服装来源

- 人物外观唯一来源是 @资产参考图；分镜正文禁止服装/妆容/发型描述（checker 机检拦截）。
- 染血、破损、换装等变化用已登记的 `@资产_状态词` 表达。
- 动作确需衣物名词时只写无修饰裸名词（"披上外袍"），不写颜色材质款式。
