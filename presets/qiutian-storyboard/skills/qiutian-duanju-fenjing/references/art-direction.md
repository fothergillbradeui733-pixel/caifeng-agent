# 美术指导（阶段二·逐场美术设计）

美术指导管"画面里有什么、光从哪来、什么质感"。**只设计和登记，不编造**。

## 铁律

1. **陈设必须有据**：场景陈设只来自剧本原文或场景资产卡的固定陈设。不得凭空添加家具、摆件来"丰富画面"（权力站位同理：只用场景已有锚点）。
2. **锁定基调不可动**：项目 lockedToneLine（风格+质感+色调+材质）逐字复用；本场特有的光源、天气、时段、情绪氛围写进该 Block 基调行的**补充段**，不重写项目基调。
3. **服装零文字**：人物外观归 @资产参考图；美术不碰服装描述（checker 拦截）。
4. **明亮优先**：光影默认明亮通透；压迫感靠人物关系与站位，不靠压暗。确需暗场必须写明光源与亮度兜底（如"暖黄灯光明亮柔和、屋内通透"）。

## 逐场美术清单（每场一份，内部）

```text
场次：@地点（日/夜）
  主光源：门窗自然光 / 顶灯 / 台灯 / 路灯 / 烛火…（方向写明）
  辅助光与光比：有无逆光、轮廓光、明暗交界
  关键陈设：剧本写明的 + 资产卡固定陈设（逐条列，标来源）
  年代质感符号：2–3 个可拍细节（旧物、痕迹、材质），必须剧本或资产卡有据
  色温与情绪：本场色温倾向 + 服务什么情绪
  超现实光色（如有）：全集唯一性声明（如金手指显灵的暗金水纹）
```

## 光源设计动机表

| 光源处理 | 戏剧动机 | 适用 |
|---|---|---|
| 门窗光通透 | 日常、坦荡、无处藏 | 家庭戏、谈判 |
| 门缝/窗框窄光 | 窥视、秘密、一线希望 | 密谈、偷听、转机 |
| 顶光硬光 | 审判、压迫、神性 | 审讯、分家、祭台式场面 |
| 单光源夜景 | 亲密、孤独、暗流 | 夜谈、显灵、守护 |
| 逆光剪影 | 情绪到顶放弃细节 | 离别、牺牲、重逢 |
| 冷暖同框 | 两个世界、同心不同温 | 对峙、疏离 |
| 光线骤变 | 希望生灭 | 变故、转晴 |

## 画幅美术

### 竖屏 9:16

- 竖屏纵深三层：前景压力层（门框/道具/遮挡）→ 中景主体层 → 后景反应层；
- 关键信息在中央约 80% 安全区；顶部约10%、底部约15%、右侧约12% 是常见 UI 覆盖区，不放关键脸/手/道具；
- 年代质感靠"可拍细节"：磨损的桌沿、发黄的契纸、搪瓷缸的水垢——不靠旁白解释。

### 横屏 16:9

- 水平三层：前景主体—中景主体—背景环境，同框信息量大于竖屏；
- 大远景/全景是横屏特权：环境与人的比例关系（大远景小人物）优先用横屏表达；
- 安全区：顶部约 10%、底部约 15% 为平台标题/字幕覆盖区；左右两侧比竖屏宽松，但视线方向留白要主动管理；
- 群像横排入画，陈设与道具沿水平轴分布，避免主体全挤在画面中央。

## 与资产索引联动

- 场景卡固定陈设 = 美术清单的默认项；剧本新出现的承重道具登记进资产索引（缺口则进缺口清单）；
- 美术清单里的每个陈设在正文首次入画时自然带出，不堆砌陈列。
