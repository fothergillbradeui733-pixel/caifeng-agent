# 单 Block 完整注释范例（新交付格式）

> 摘自《八零分家》EP-01 实跑 PASS 样本（竖屏 9:16）。注释行为讲解，不写入交付文件。
> 横屏 16:9 项目沿用同一格式，差异仅在基调行的画幅词与构图布局句写法（见 landscape-cinema-language.md 第七节）。

```text
── Block 3 | 12s ──
```
Block 头：编号连续，时长 ≤15s。同场戏切镜用"（接）"后缀只在剧本同场连续时。

```text
📍 场景：@秦家堂屋（日）
```
场景行：@资产名 + 时段。资产名必须来自项目资产库，禁止自造地点名。

```text
👤 出场：@秦川_分家装，@何秀梅_强势期，@赵桂兰_病中，@秦志远_县厂装
```
出场行：只列**镜头可见**角色主体（按状态资产名，见 character-cards 角色状态索引）。背景群像不入此行。

```text
视频整体基调：写实电影感、年代剧质感、暖黄色调、明亮日景室内自然光、门窗光通透、情绪压到最低、真实肤质与物理光影、胶片颗粒、9:16竖屏、无字幕、无水印。
```
基调行：项目锁定行逐字复用 + 本场光影/情绪补充。**不写地域词、不写服装。**

```text
🧭 起始空间状态：@秦川_分家装（站在供桌另一侧，盯着契纸最后一栏）｜@何秀梅_强势期（站在供桌旁）｜@赵桂兰_病中（坐在低凳上，佝偻着背）｜@秦志远_县厂装（倚在墙边）
```
起始空间状态：每条目以姿态动词开头（站/坐/倚…）；必须等于上一 Block 的内部结束状态（连续场）。机检只认姿态前缀。

```text
具体故事情节描述：
🎬 镜头 1【秦川 近景 缓推】
@秦川_分家装 盯住契纸最后一栏，嘴角绷紧，一字一顿：娘呢？
```
镜头行：`🎬 镜头 N【取景主体 景别 运镜】`，空格分隔，从 1 编号。
- 取景主体点名（人物/道具/地点），禁止裸景别。
- **镜头角度与机位直接写进正文**（"镜头从低处仰起""俯拍下去""越过他的肩"），不设独立角度行。
- 台词揉入正文，不单独成行。
- 微表情写具体可渲染（嘴角绷紧），禁止塑料表演词。

```text
🎬 镜头 2【何秀梅 近景 固定】
@何秀梅_强势期 毫不迟疑，眼风扫向低凳方向：娘也归你。你不是最孝顺吗？
```
一镜一拍。这句是本 Block 的核心爆点台词，S 级完整保留。

```text
🎬 镜头 3【赵桂兰 近景 固定】
@赵桂兰_病中 咳得弯下腰，药包从袖口滑出坠在地上，她撑着桌沿缓气，没有去捡；后景 @秦志远_县厂装 虚焦里往前挪了半步，又停住。
```
同框非说话角色必须有可见反应（@秦志远 虚焦挪步又停住）。道具状态变化（药包坠地）写清楚，供下一 Block 承接。

```text
【音频规范】
角色音色：@秦川_分家装音色=（【男青年】嗓音演绎，音色朴实清朗，音调偏中，带轻微华中乡音。）｜@何秀梅_强势期音色=（【女青年】嗓音演绎，音色明快偏硬，音调偏高，带轻微华中乡音。）
```
音色行：**有项目权威音色锁定（character-cards.md「角色音色锁定」）必须逐字抄**，禁止自写。多角色用 ｜ 分隔。本集无台词的角色可不列音色。

```text
全局音轨：堂屋环境音、剧烈咳嗽声、药包坠地闷响、对白；无内心OS；无BGM。
```
全局音轨：环境音 → 关键动作声 → 对白；明确 OS 与 BGM 有无。

```text
最后一镜结束站位：@秦川_分家装（站在供桌另一侧，目光落在娘身上）｜@何秀梅_强势期（站在供桌旁）｜@赵桂兰_病中（坐在低凳上弯腰咳嗽）｜@秦志远_县厂装（站在墙边）。
```
结束站位：公开的本 Block 收束状态，是下一 Block 起始状态的审计基准。条目同样以姿态动词开头。

```text
🚫 无BGM，无字幕，无水印，人物外观沿用参考图与真实肤质，禁止生成克隆人。禁止改变视频风格。
```
禁用行：固定收尾。

## 常见违规对照

| 违规 | 正确写法 |
|---|---|
| `镜头 1 持续时间: 3s【特写 + 固定镜头】`（V8残留） | `🎬 镜头 1【@分家契 特写 固定】` |
| `镜头角度：俯拍` 独立行 | 角度意图揉进正文或用运镜词 |
| `画面描述：她扬起下巴` | 直接写正文 |
| `台词：@何秀梅：“先分家。”` | `@何秀梅_强势期 扬起下巴：先把家分了！` |
| `抽卡风险：中` | 删除，复杂度只留内部台账 |
| `他身穿灰布褂` | 删除，外观归 @资产参考图 |
| 结束站位写 `@秦川_分家装（@秦家堂屋）` | 姿态动词开头：`@秦川_分家装（站在供桌另一侧）` |
