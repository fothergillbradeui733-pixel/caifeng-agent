# 动作指导（阶段二·条件加载）

触发条件：剧本出现追逐、推搡、拳脚、械斗、摔跌、救援、车祸、扭打等动作场面。**有动作戏必须走本文件，不许凭感觉写。**

## 一、动作五段拆解法（每个动作事件必拆）

```text
① 起因：谁先动、为什么动（情绪或剧情触发点）
② 动作路径：从 A 到 B 的完整轨迹（起点→过程→终点，写清身体怎么动）
③ 接触/躲避：打中/被挡/躲开/抓住——接触点、力度、身体变形
④ 人物反馈：生理反应（踉跄、捂痛处、脱力）+ 情绪反应（愣、怒、怕）
⑤ 结束状态：所有人最终的位置、姿态、伤势——写进空间台账，供下一 Block 继承
```

缺任何一段都是动作戏穿帮源。剧本跳过中间过程时，动作指导**补全物理过程**（这不算编剧情，算可拍化）。

## 二、动作 Block 拆分

- **在动作相位稳定点切**：蓄力完成时、一击命中后、双方分开站定、倒地 settle 之后；
- **禁止**在接触进行中、翻滚半途、挥击中点切 Block；
- 高复杂度动作（多人扭打、连续攻防）→ 一个 Block 只装**一个动作相位**：
  - Block A：对峙蓄力（压迫累积）
  - Block B：关键一击（特写/插入镜拍接触点）
  - Block C：后果与反应（settle + 情绪落点）
- 动作戏同样受拆分四原则约束（director-plan.md）。难度只决定拆分粒度（一个动作相位一个 Block），**不决定拍不拍**——剧本要求的动作场面必须完整保留，靠拆细、锚点、抽卡保效果。

## 三、动作镜头法

标准动作叙事链（按需取舍）：

1. **建立空间**：全景交代双方位置与距离（距离=张力）；
2. **跟随路径**：跟移/横移拍动作轨迹；
3. **关键接触**：插入镜/大特写拍接触点（拳头落点、手抓衣领、链条断裂）——动作戏**关键接触点给特写比全景更有效**（竖屏尤甚，横屏同样适用）；
4. **反应镜头**：被打者/旁观者的反应是本段情绪落点；
5. **声音兜底**：画外撞击声、喘息声补全画内没拍到的力度。

原则：**先拍清路径，再谈冲击力**。观众看不清怎么打的动作戏=失败。

## 四、真实物理（仿真人线铁律）

- 重力、惯性、反应时间、体力消耗都要对：人被打会踉跄不会平移，跑动停不下来要缓冲；
- 不用威亚感、慢动作滥用、无接触打击；升格只给"瞬间太重"的一击（见镜头语言库·速度）；
- 超自然元素（金手指触发等）忠实保留剧情，用克制的实拍合成语言（唯一超现实光色等），其余保持写实物理。

## 五、伤势连续性（动作戏最容易穿帮处）

- 伤势是**状态**：破皮、渗血、淤青、跛行——一旦发生，写进空间台账和集尾快照；
- 跨 Block：上一 Block 指腹渗血，下一 Block 该手还在渗血或已擦拭（必须有动作交代）；
- 跨集：伤没好的集数里持续存在；痊愈需要剧本时间依据；
- 服装染血/破损不用文字描述，用 `@资产_状态词` 表达（服装来源铁律）。
