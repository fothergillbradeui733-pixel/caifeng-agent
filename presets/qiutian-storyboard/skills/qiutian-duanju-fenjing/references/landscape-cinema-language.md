# 横屏 16:9 方法论：构图 / 空间设计 / 导演设计 / 镜头语言（电影质感 & 电视剧质感）

横屏仿真人项目（模块 B）**必读**。本文件不是随手编排：核心概念均出自标准电影语法
（英文 Wikipedia：180-degree rule、Rule of thirds、Lead room、Negative space、Deep focus、
Master shot、Coverage、Over-the-shoulder shot、Establishing shot、Long take、Two shot、
Eyeline match、Single/Multiple-camera setup、Blocking、Aspect ratio），并改写为适配分镜
Block 的可执行规则。标注〔AI适配〕的条目是视频生成场景下的落地调整。

## 一、横屏为什么不同（画幅本体）

- 竖屏 9:16 是"人的画幅"：人体纵向天然占满画面，构图以单人纵深为主。
- 横屏 16:9 是"关系与空间的画幅"：水平宽度让多主体、环境、左右关系同框成立。
- 行业事实：电影标准画幅 1.85:1 与 2.39:1、电视标准画幅 16:9 都是横屏（Aspect ratio 条目）。
  横屏天然携带"电影/剧集"观看习惯——这就是横屏更讲究电影质感、电视剧质感的原因。
- **分镜核心转变**：构图单位从"单人占满"变成"主体间关系与画面布局"。写横屏正文时，
  先想画面里有什么布局，再想谁说话。

## 二、横屏构图语法（六条，全部有出处）

1. **三分法（Rule of thirds）**：画面想象成 3×3 九宫格，主体放在三分线或交点上，
   比居中产生更多张力与趣味。横屏里左右三分线是主体主位；**居中构图只留给有意图的场合**
   （对称、权力展示、审讯、仪式感），不默认居中。
2. **视线留白（Lead room / nose room）**：面朝或移动方向的主体，面前要留空间——
   观众视线习惯"主体前方应看到一些东西"。看画左就画左留白；故意反向留白（面贴画框边缘）
   制造压迫/阻塞感，必须有戏剧动机才用。
3. **负空间（Negative space）**：主体周围的空白区域可以反过来成为画面"真正的主体"——
   孤独、空旷、权力压迫。横屏特权：把角色压到画面一侧，用大面积空间表达孤立无援。
4. **平衡与失衡**：横屏左右有"重量"——主体大小、明暗、线条方向都产生视觉重量。
   双人镜头左右均衡=关系对等；一侧大一侧小、一侧空一侧满=权力差、疏离、失衡。
   写对峙戏先定"这镜要平衡还是失衡"。
5. **框中框与引导线**：门、窗、走廊、桌沿形成画中画框或对角引导线，把视线引向主体。
   横屏宽度让这类构图更易成立；用框中框表达"被困/被窥视/旁观"。
6. **景深二选一（每个镜头开拍前定）**：
   - **深焦（Deep focus）**：前景、中景、背景全部清晰——横屏特权，多平面调度
     （前景障碍/中景主体/后景反应同时可读）。建场、群像、人与环境命运感用深焦。
   - **浅景深**：隔离主体、虚化环境——情绪特写用；横屏浅景深特写必须同时管理左右负空间。

## 三、横屏空间设计（水平轴语法）

1. **180度轴线规则**：两个角色之间有一条想象轴线，摄影机保持在轴线同一侧拍摄，
   则 @A 恒在 @B 的同一画侧（如 @A 恒画右、@B 恒画左）。**越轴（jumping the line）
   会让观众瞬间失去左右方位感**。确需越轴必须有动机：角色移动换位、摄影机运动越轴、
   或插入中性镜头（正面/背面/垂直俯拍）过渡。越轴在空间台账登记为"越轴事件"并写依据。
2. **左/中/右三区位**：横屏走位的基本坐标。多角色场景在空间台账登记
   `@角色=画左/中/画右`（＋前/中/后层次）；位置变化必须有"从 A 到 B"移动事件。
3. **视线匹配（Eyeline match）**：角色看画外→下一镜接其所看之物；视线高度与方向必须匹配——
   A 俯看画左的 B，反打 B 就要仰看画右的 A。视线不匹配=空间假。
4. **水平方向一致性**：入场/离场/追逐在横轴上保持方向约定（回家=画左往画右；
   离去=画右往画左；追逐双方方向恒定）。无动机反向=空间混乱。
5. **走位（Blocking）**：横屏允许"边走边谈""横穿画面""后景人物走向前景"。
   用水平移动承载权力变化：谁主动走向谁、谁背身离开、谁被挤出画面——
   走位是横屏的台词之外的剧本。
6. 〔AI适配〕银幕约定登记：原文没有左右依据时，按 spatial-state-contract.md 登记为
   银幕约定（basis=银幕约定），全场景保持，重建场才可重定。

## 四、横屏导演设计（建场—主镜—覆盖 导演法）

1. **建场三步（coverage 方法）**：
   - **建置镜头（Establishing shot）**：场景开头用远景/大远景建立地点、时间、
     人物与物体的关系——横屏第一优先；
   - **主镜头（Master shot）**：一个机位从头到尾拍下整场动作与全部角色（通常是全景），
     是全场镜头设计的地基；
   - **覆盖（Coverage）**：在主镜头之上补拍关键时刻——双人镜头、近景、特写、道具插入。
   - **落到 Block**：一场戏的前一个 Block 承担建场（大远景/全景深焦），
     后续 Block 做覆盖拆解（双人/近景/特写）。**连续三个镜头都不建场=空间悬空，禁止。**
2. **对话戏标准件（shot-reverse-shot + OTS）**：
   - **过肩镜头（OTS）**：越过听者肩头拍说话者——肩的存在维持空间关系，同时拿到表情。
     正反打过肩来回切，是横屏对话的默认语法；
   - **双人镜头（Two shot）**：两人同框——并肩（同盟/平等）或一前一后（距离/层级），
     不必相邻；
   - **换肩信号**：从"越过 A 肩拍 B"换成"越过 B 肩拍 A"，标记权力/主动权的转移，
     用在台词落点处。
3. **长镜头（Long take）**：显著长于常规剪辑节奏的镜头，常伴随显著的摄影机运动与
   精心走位。横屏用它换"一口气的真实感"（跟移穿场、环绕、升降一镜）。
   〔AI适配〕长镜头是高复杂度生成项：按铁律保留剧本要求，实现层拆更细的 Block、
   加参考锚点、预留抽卡，用尾帧衔接拼回长镜头观感——不因难度删。
4. **每 Block 开拍前的横屏五问**（写进 Block skeleton）：
   - 主体布局：左/中/右？前/中/后？
   - 轴线在哪？本 Block 是否越轴（有动机才许）？
   - 留白方向：lead room 给哪边？负空间表达什么？
   - 景深：深焦多平面还是浅景深隔离？
   - 本场建场—覆盖进度：谁建场、谁覆盖？

## 五、电影质感 vs 电视剧质感（横屏两条质感路线）

横屏项目开工时（阶段零追问）二选一，全剧保持。学理根基：电影传统是**单机位**
（single-camera setup，一台摄影机逐镜头拍，每镜单独布光），剧集传统是**多机位**
（multiple-camera setup，多台摄影机同时覆盖多角度）。两种传统塑造了两种质感：

| 维度 | 电影质感（cinematic） | 电视剧质感（episodic） |
|---|---|---|
| 拍摄传统 | 单机位：一镜一个强意图，逐镜精雕 | 多机位：多角度同时覆盖，信息优先 |
| 镜头密度 | 镜头少而长，敢留白、敢停顿 | 镜头多而密，正反打与反应镜头频繁 |
| 光影 | 有动机光源（窗光/实景灯），明暗有层次对比 | 均匀明亮，人脸清晰优先 |
| 景深 | 浅景深多，隔离主体、突出情绪 | 深焦/双人镜头多，保证空间信息可读 |
| 构图 | 负空间、对称、框中框、刻意失衡 | 实用构图，主体明确，安全区保守 |
| 剪辑节奏 | 慢，长镜头与凝视镜头多 | 快，台词-反应交替密 |
| 色调 | 统一色调、调色个性强 | 自然色、跨集稳定 |
| 适配题材 | 品牌片、悬疑、作者气质剧、命运感叙事 | 家庭伦理、都市情感、职场、长对话剧 |

**铁律：电影质感≠暗。** 光影明亮通透的铁律仍然成立——电影质感靠构图、景深、
有动机光源与节奏表达，不靠压暗画面。

〔AI适配〕质感路线落进交付的方式：
- 写进文件头「构图策略」章节（选哪条路线＋为什么适配本剧）；
- 写进项目 lockedToneLine 的"光影/镜头质感"段（如"浅景深、有动机光源、电影感调色"
  vs"深焦通透、均匀自然光、剧集感"）；
- 逐 Block 执行差异：电影质感给留白与长镜头更多耐心；电视剧质感给反应镜头更多镜头数。

## 六、横屏镜头语言要点（与 camera-language-library.md 联用）

通用镜头语言（景别、运镜、特殊运镜百科）全部沿用 camera-language-library.md；
横屏另有四条专属偏好：

1. **横摇/横移是横屏母语**：水平扫过空间、跟随横向走位，天然契合画幅；
   竖屏慎用大幅横摇，横屏可大胆用。
2. **大远景建场是横屏特权**：环境与人的比例（大远景里的小人物）承载命运感，
   横屏项目每集至少给一次；竖屏基本放弃这个景别。
3. **深焦多平面调度**：前景—中景—后景三层同框清晰，是横屏信息密度最高的手法；
   写清每层的主体与动作，不许含糊。
4. **升降/轨道宽景**：crane 起落揭示空间规模，横屏画幅装得下；高复杂度项，
   按铁律保留＋拆细实现。

## 七、横屏交付与机检衔接

- 交付格式沿用 2026-08-13 拍板格式（与模块 A 同一套），文件头标题写"横屏16:9分镜"；
  「构图策略」章节写横屏版：轴线登记、建场—覆盖计划、lead room/负空间主要意图、质感路线。
- 出场预算：横屏建议 2–4 个镜头可见主体（竖屏 1–3），群像可超但必须写清
  左/中/右与主表演焦点。
- 正文写布局：横屏镜头把位置写成布局句（"@A立画左…@B坐画右…两人之间一张方桌"），
  不是竖屏式的单人堆叠。
- 机检脚本画幅无关（check_storyboard.py / check_spatial_continuity.py 只查结构），
  横屏的构图/轴线/质感质量靠阶段四语义审查按下列五点把关：
  1. 每场有建场（establishing/master）吗？
  2. 轴线登记了吗？无动机越轴为零？
  3. 对话戏有 OTS/双人镜头层次，不是全程特写？
  4. lead room/负空间是有意的（写得出表达什么）？
  5. 镜头/光影/节奏与所选质感路线（电影/电视剧）一致？
