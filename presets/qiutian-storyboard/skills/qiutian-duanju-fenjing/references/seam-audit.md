# 相邻 Block 缝合审计（smooth-seam gate）

写正文后、交付前，对每对 `Block N → Block N+1` 逐对审计。连续场（同场景同时段）与跳切（换场/换时间）规则不同。

## 连续场

硬等式：

```text
Block N 内部结束状态 == Block N+1 🧭起始空间状态
```

逐维度核对：

1. 场景与时间；
2. 角色在场/画外状态；
3. 姿态与位置锚点；
4. 持物与交接完成度；
5. 伤势与可见动作状态；
6. 朝向/视线（仅在已建立时）；
7. 银幕方向、运动方向、轴线约定；
8. 台词/动作阶段；
9. 尾镜与首镜的戏剧功能；
10. 景别/角度/运镜的切换关系。

然后做**动词级源证据扫查**：两个 Block 里每个移动、姿态变化、道具交互、身体接触、朝向、视线短语都要对剧本原文或已建立的进入状态。一句"看起来合理"的话，若创造了无依据的空间关系，就是禁止的。

源没建立的空间细节，**不为连续性编造**——改镜头方案。

## 导演动机接缝表

| 上一尾镜 | 下一首镜 | 适用 |
|---|---|---|
| 动作中景 | 反应特写 | 动作/台词落点 |
| 说话人近景 | 听者中近/过肩 | 关系反应 |
| 道具插入 | 反应特写 | 证据/信息改变局面 |
| 移动到达锚点 | 同锚点新角度 | 节拍原地继续 |
| 特写爽点/揭示 | 全景重建 | 换场/换时间 |

## smooth-seam gate

先判连续，再谈变化：

```text
状态连续 + 动作阶段连续 + ≥2个视觉桥锚点 + 轴线/运动方向连续 + 有动机的镜头变化
= 平滑接缝
```

桥锚点从以下选至少两个：

- 主体既定银幕侧/画面区域；
- 同一位置/场景锚点；
- 关键道具及其既定位置；
- 同一运动方向；
- 已建立的台词/动作轴线或有依据的视线。

### 镜头变量控制（独立生成的 Block 之间）

- **没有真实提供的尾帧素材时**：连续场跨缝**恰好一个**有动机的主变量——景别、视角/构图、运镜三选一。
  - 景别变 → 优先保角度、轴线、主体银幕侧、动作阶段；
  - 视角/构图变 → 优先保景别、轴线、主体位置锚点、动作阶段；
  - 运镜变 → 让出画运镜先落到可读的静止相位，再起新模式。
- **变两个以上维度** → 必须有强桥：道具插入、反应交接、揭示、到达锚点的完整移动、或明确的时空重置。
- **零变化** → 仅当有真实尾帧素材锚定，或有源支持的遮挡/插入镜遮住了再生接缝。
- **同景别同角度** → 仅当视角/构图或运镜是那唯一的有动机变量。不许为"看起来不同"而多维乱变。
- 绝不为视觉变化越轴或反向运动。

### 拒收的接缝

- 未完成动作被重置；
- 主体无桥跳到另一画面区域；
- 道具无故移位；
- 方向反转；
- 景别大跳+角度跳+构图重置+新运镜同时发生且无依据。

接缝不过 → 改 Block 边界或镜头方案；**不许编人物移动、家具、朝向或剧情动作来修**。

## 内部缝合记录（写正文前，每对一行）

```text
出画功能：…
入画功能：…
桥锚点：… + …
主镜头变化：景别 / 视角构图 / 运镜 / 有尾帧或遮挡的零变化
理由：…
结果：过 / 改边界 / 改镜头方案
```

## 范例

源：@陈远 持报告从门口走到餐桌对面停下，面向 @母亲；@母亲 坐主位双手按桌沿，抬眼看他。

Block 1 内部结束状态：

```text
@陈远（站在餐桌对面，手持报告，面向母亲）
@母亲（坐在餐桌主位，双手按住桌沿，抬眼看向陈远）
```

Block 2 公开同一状态：

```text
🧭 起始空间状态：@陈远（站在餐桌对面，手持报告，面向母亲）｜@母亲（坐在餐桌主位，双手按住桌沿，抬眼看向陈远）
```

接缝：Block 1 尾镜中景跟移@陈远到桌前站定（运镜已收住）→ Block 2 首镜@母亲中近景固定反应。桥锚点：同一桌关系 + @母亲既定主位侧。主变量：景别。轴线、银幕关系不变。
