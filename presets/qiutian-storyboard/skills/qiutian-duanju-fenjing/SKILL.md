# 秋天短剧转分镜专属技能（唯一权威）

本技能是短剧转分镜的统一入口，由以下原技能合并而成（原目录已归档）：

- **storyboard-spatial-continuity-core** → 空间站位与连续性合同

## 阶段零：苏格拉底式开工确认 → 模块路由（任何项目第一动作）

**不许拿到剧本就直接写分镜。** 先苏格拉底式提问确认三要素，一次只问一个问题，
用户答完一个再问下一个（用户一句话同时答全的，复述确认即可）：

1. **需求**：哪部剧、哪一集/哪些集？剧本文件在哪？（没有剧本先问剧本）
2. **画幅**：竖屏 9:16（短剧默认）还是横屏 16:9（剧集/电影感）？
3. **渲染风格**：仿真人（真人写实）还是 3D 漫剧（三维渲染动漫风）？
4. **横屏追问**（仅画幅=横屏时）：要**电影质感**还是**电视剧质感**？
   （差异见 `references/landscape-cinema-language.md` 第五节对照表）

剧本头写明模式也**不能跳过确认**——复述"题材+画幅+渲染风格（+质感路线）"请用户拍板。
确认后按路由表走对应模块，全剧固定，中途换模块/换质感必须用户明确指令：

| 确认结果 | 路由模块 | 执行依据 |
|---|---|---|
| 仿真人 + 竖屏 9:16 | **模块 A** | 本文件铁律＋交付格式＋五阶段工作流 |
| 仿真人 + 横屏 16:9 | **模块 B** | 模块 A 全部规则 ＋ `references/landscape-cinema-language.md`（必读）＋所选质感路线 |
| 3D 漫剧（横屏） | **模块 C** | `references/3d-v10-sop.md`（主流程）＋ `references/3d-prompt-format.md`（格式）＋ `references/3d-module-packs.md`（风格包/题材包/特殊机制）＋ `references/3d-project-config.md`（项目配置） |

> 模块 A/B 与模块 C 的交付格式不同（拍板时间不同）：A/B 用 2026-08-13 新格式；
> C 用 V10 格式（含单镜时长与镜头角度行，是 V10 合同的一部分）。机检脚本也分线：
> A/B 跑 check_storyboard.py ＋ check_spatial_continuity.py；C 跑 audit_3d_storyboards.py。
> 铁律（只拆不编、参考图权威、Block≤15s、禁止同上、@资产名、AI难度不删内容）三线通用。

## 铁律（违反即返工）

**适用范围**：②③④⑤⑦⑧ 三线通用；①⑥ 为模块 A/B 格式专属——模块 C 的 V10 格式本身含单镜时长行、镜头角度行、独立台词/声线行，那是 V10 合同要求，不是 V8 残留。

1. **格式唯一**：模块 A/B 只输出 2026-08-13 拍板的交付格式（见下）。禁止 V8 残留：单镜时长行、镜头角度行、`画面描述：`标签、独立`台词：`/`声线：`行、公开风险字段。
2. **只拆不编**：保留原剧本情节、关系、动机、道具、证据、台词分量与揭示。台词零增删是默认；确需压缩走 S/A/B/C 分级且 C 级删除不得断因果。
3. **参考图权威**：人物外观只认上传的 @资产参考图。分镜正文**禁止服装、妆容、发型描述**。外观状态变化用中性状态资产（如 @角色_状态02）表达，不用服装词。
4. **Block ≤ 15s**，目标 10–14s。
5. **每个 Block 是独立完整的生成提示词**，禁止"同上"。
6. **台词揉进正文**，不单独成行（模块 A/B；模块 C 按 V10 用独立台词行）。
7. **人物一律 @资产名 指代**，禁止"黑脸汉子""那个男人"等模糊文学表达。
8. **AI 难度不删内容**：难度只影响"怎么实现"，不影响"写不写"。剧本要求的剧情、台词、动作、特殊运镜一律保留，靠拆细、锚点、抽卡、尾帧衔接保效果。

## 交付格式（2026-08-13 拍板）

```text
# 《剧名》第XX集：标题｜风格 {竖屏9:16|横屏16:9}分镜 VX

## 剧情摘要
（出处、本集目标、总时长、画幅、Block数量）

## 导演编排总纲
（全集镜头弧线 + 每 Block 主动作一句话）

## 构图策略（竖屏/横屏按画幅二选一） / 资产说明 / 本集使用人物资产索引

── Block N | Ys ──

📍 场景：@地点（日/夜）
👤 出场：@角色A，@角色B
视频整体基调：{项目锁定基调逐字复用，不描述服装}
🧭 起始空间状态：@角色A（姿态+位置锚点，持物）｜@角色B（…）

具体故事情节描述：
🎬 镜头 1【取景主体 景别 运镜】
正文（动作、表演、台词揉入、环境变化）。
🎬 镜头 2【…】
…

【音频规范】
角色音色：@角色A音色=（五维模板）｜@角色B音色=（五维模板）
全局音轨：环境音、动作声、对白；无内心OS；无BGM。
最后一镜结束站位：@角色A（姿态+位置）｜@角色B（…）。
🚫 无BGM，无字幕，无水印，人物外观沿用参考图与真实肤质，禁止生成克隆人。禁止改变视频风格。
```

### 字段规则

- **镜头行**：`🎬 镜头 N【取景主体 景别 运镜】`，Block 内从 1 连续编号；空格分隔。取景主体必须点名（@角色/@道具/@地点，群像写实际成员）；景别以标准词结尾（大远景/远景/全景/中全景/中景/中近景/近景/特写/大特写，可加"双人"前缀，如"双人近景"）；运镜一两个词（固定/缓推/缓拉/跟移/摇移/甩镜/环绕/手持…）。**角度词（俯拍/仰拍/过肩/主观等）不得写进镜头括号**，只能揉进正文。
- **镜头角度与机位直接写进镜头正文**（如"镜头从低处仰起""俯拍下去""越过他的肩拍向桌面""主观视角"），不单独设"镜头角度："行。角度必须服务戏剧（见 camera-language-library 第四节），无动机的角度词不写。
- **禁止**在镜头括号内写爆点、爽点、钩子、情绪词。
- **一镜一拍**：一个镜头一个主节拍；无关动作或竞争焦点拆镜。取景主体必须是该镜画面描述的中心，主体与主节拍打架就拆。
- **音色五维模板**：`@角色音色=（【类型】嗓音演绎，音色XX，音调XX，…。）`。**有项目权威音色锁定（如 character-cards.md「角色音色锁定」）时必须逐字抄锁定值，禁止自写**；无锁定时五维自拟、以"标准普通话。"收尾。
- **OS**：内心 OS 本体嘴巴不动。
- **出场行**只列本 Block 镜头可见角色主体；背景龙套/群像在画面描述里作为背景层处理，不逐个列出。

## 工作流（模块 A/B，每集必须按序走完，不许跳步）

### 阶段一：开工准备（阶段零确认完成后）
1. 阶段零确认已完成（需求/画幅/渲染风格；横屏另加质感路线）——未确认禁止进入本阶段。
2. **资产索引**（写正文前必做，按 `references/asset-index.md` 执行）：读权威来源并建立本集资产索引表——角色/场景/道具 @资产名、音色锁定、角色状态索引（多状态角色挂本集适用状态卡）；逐场覆盖预检，缺口登记缺口清单。音色有权威锁定必须逐字抄，禁止自写。
3. 锁定项目基调行（lockedToneLine）：写实/3D风格 + 年代剧质感（或题材对应质感）+ 色调（默认暖黄，可按场次换）+ 光影/材质。**基调行不写地域词**（不写"华中农村"等），地域感靠场景/道具/习俗呈现。锁定后每个 Block 逐字复用。

### 阶段二：四岗位规划（写正文前，内部完成）

阶段二按"剧组四个岗位"分工执行，产出物精华写进文件头「导演编排总纲」，台账留内部：

4. **源覆盖地图**（总编）：逐场戏提取，证明全集覆盖、零遗漏；台词 S/A/B/C 分级（S 完整保留；A 压缩保核；B 转动作/道具/反应；C 仅因果不断时可删）。
5. **导演**（`references/director-plan.md`，必做）：整集导演计划（场景顺序/节拍功能与观众收益/观看入口/核心道具流/预定剪辑）＋每 Block skeleton（戏剧任务/主节拍/必需台词/关键反应/时长估算/预期镜头数/生成复杂度台账）。每拍标功能与观看入口。
6. **美术指导**（`references/art-direction.md`，必做）：逐场美术清单——主光源方向、关键陈设（剧本/资产卡有据，禁止凭空加家具）、年代质感符号、色温与情绪、超现实光色唯一性。本场特有光影写进该 Block 基调补充段，不动项目 lockedToneLine。
7. **动作指导**（`references/action-direction.md`，有动作戏时必做）：动作五段拆解（起因/路径/接触/反馈/结束状态）、相位稳定点切 Block、真实物理、伤势连续性登记。
8. **拍摄指导**（`references/camera-language-library.md`，必做）：每 Block 先定情绪曲线，再配镜头弧线（推=压迫/拉=释放/固定=见证），情绪拐点处用景深/光影/构图变化；一 Block 一条镜头主动作；手法是盐不是主菜。
9. **空间台账**（`references/spatial-state-contract.md`）：起始状态、逐镜头状态变化、结束状态、画外角色、银幕约定。
10. **Block 边界四原则**（`references/director-plan.md` 第三节，写正文前定完所有边界）：
    - ①**按剧情拆**：动作完成/台词落点/揭示交接/到达锚点/时空切换处切；
    - ②**按镜头拆**：镜头弧线换挡处开新 Block（压迫→释放、跟随→定格），不许无缘由重复同一种推进；
    - ③**按AI生成难度拆**：命中高复杂度（多人调度/身体接触/精确交接/长屏显文字）→ 拆得更细、加参考锚点、预留抽卡；**难度只决定怎么生成，不决定写不写——剧本要求的剧情与手法绝不因难度删改**；
    - ④**按衔接拆**：定边界后预演接缝（smooth-seam gate），过不去就移边界或换场重建。
    - **铁律：15 秒是硬上限不是拆分依据，禁止机械卡秒拆分。**

### 阶段三：写正文
11. 按交付格式逐 Block 写，执行阶段二的导演计划；角度与机位揉进镜头正文。
12. 台词揉入正文；同框非说话角色必须有可见反应；微表情写具体可渲染；动作戏按五段拆解落地。

### 阶段四：质量闸门（每道都是硬门槛）
13. **确定性机检**（两道都跑）：
    - `python3 scripts/check_storyboard.py <文件>` — 交付格式合同
    - `python3 scripts/check_spatial_continuity.py <文件>` — 空间状态合同
14. **源证据扫查**：给每个动作、姿态变化、道具交互、身体接触、朝向、视线动词划底线，逐一核剧本原文；无依据的删除或改中性表达。关系性视线（看向/盯着/背对/转向）没有原文或已建立状态支撑就不写。
15. **相邻 Block 缝合审计**（smooth-seam gate，见 references/seam-audit.md）：逐对审 Block N→N+1；连续场要求上一结束状态=下一开始状态；无尾帧素材时跨缝**恰好一个**有动机的镜头变量（景别/视角构图/运镜三选一），≥2 个视觉桥锚点。
16. **独立语义审查**：以新鲜上下文（或独立调用）按 references/semantic-review.md 审源忠实、编造事实、节奏可行性、空间/道具连续性、基调漂移；问题必须引证据。最多两轮自动修复，仍有高危歧义上报用户。
17. 闸门全过后才交付；报告各机检结果与五点位自查（钩子+笑/泪/爆/爽/反转点密集、不掺水、连贯、紧凑）。

### 阶段五：跨集
18. 每集收尾写**集尾空间快照**（内部或附文件末尾）：逐角色姿态/位置/持物/伤势/去向、未解悬念、关键道具状态、下集触发点、直续/跳跃。直续集必须继承。
19. 多集后跑跨集资产状态审计：角色状态切换锚（如 EP06 起换机修装）、核心道具流转。

## 仿真人线规则（原 storyboard-faux-live-action）

### 适用项目

- 中文短剧：现代都市、家庭伦理、豪门总裁、复仇爽剧、甜宠虐恋、年代写实、职场/医院/校园/乡村。
- 国内平台与道具语汇：微信聊天、短视频直播、监控、亲子鉴定、病历、合同、房产证、转账记录、录音笔、热搜截图。
- 中式关系压力：婆媳、父母子女、婚恋、家族、老板下属、同学同事、邻里围观。
- 英文/海外项目同样走本线，差异见文末附录。
- **不适用**：3D漫剧、国漫、Q版OS → 走**模块 C**（见下）；除非用户明确要求跨线。

### 画幅是项目参数，不是分支

- 竖屏 9:16：短剧默认；特写、中近对峙、门/桌卡位、手机前景、浅景深优先。
- 横屏 16:9：品牌片、横屏剧集感项目；左右轴线主导、纵深调度、大远景可用（见下）。
- 开工时按阶段零确认，全剧固定，不逐集切换。
- 机检脚本画幅无关（只查 Block 结构），两种画幅共用同一套闸门。

### 横屏 16:9（模块 B）

**完整横屏方法论在 `references/landscape-cinema-language.md`（横屏项目必读，不可跳过）**，
基于标准电影语法检索整理：构图六条（三分法/视线留白/负空间/平衡失衡/框中框/景深二选一）、
水平轴空间设计（180度轴线/左中右三区位/视线匹配/方向一致/走位）、
建场—主镜—覆盖导演法（establishing→master→coverage、OTS 对话、长镜头）、
电影质感 vs 电视剧质感对照表（单机位传统 vs 多机位传统）。速览：

- **左右轴线是主轴线**：对话调度、追逐方向、对峙关系沿左右轴展开；银幕约定登记左右侧（如"@母亲恒画左、@女儿恒画右"），180度规则内保持，越轴必须有动机并登记。
- **建场先行**：每场第一个 Block 用大远景/全景深焦建场，后续 Block 做覆盖（双人/近景/特写）。
- **纵深调度**：前景主体—中景主体—背景环境三层可同框；大远景建场是横屏特权，每集至少一次。
- **群像横排**：2–4 人可横向并排入画；超过 4 个清晰身份焦点仍按主体预算拆分或降背景层。
- **负空间与视线方向**：人物视线方向留白（lead room），空的方向承载情绪或下一个入画主体。
- **安全区**：顶部约 10%、底部约 15% 为平台标题/字幕覆盖区，关键脸/手/道具不放。
- **质感路线开工时定死**（阶段零追问）：电影质感（镜头少而长/浅景深/有动机光源/敢留白）或电视剧质感（镜头密/深焦通透/反应镜头多），全剧保持。
- **其余规则与竖屏一致**：Block 契约、音色、空间台账、缝合审计、四岗位规划全部画幅通用。

### 仿真人导演规则

1. 上传 @角色参考图是外观唯一权威；正文禁止服装描述；状态变化用中性资产（@角色名_状态02）。
2. 禁止声称继承上一 Block 尾帧，除非用户真实提供了该尾帧素材。
3. 短剧节奏可强于电影写实：早钩子、频反转、可见的社会压力、锋利的爽点反应。
4. 给角色日常小动作：捏手机、筷子停顿、捋袖口、攥报告、门口停顿、藏发抖的手、瞟监控。
5. **权力站位用场景已有锚点**：餐桌主位与门口、病床与床尾、办公桌内外、沙发主座与站立区；不得凭空添家具或改人物关系。
6. **竖屏纵深刻意用**：前景手机/门框形成压力，中景承载说话主体，后景承载反应或离场路径。不编源不支持的前后位置；必要的画侧分配登记为银幕约定。
7. 打脸/爽点节奏：慢压铺垫 → 决定性台词/道具揭示 → 对手反应 → 短停留余波。
8. 情感虐恋：减少大动作；用呼吸、手、眼神、断句、沉默。
9. **禁止塑料表演词**：不写"邪魅一笑""咬牙切齿""崩溃大哭"（除非原文明写）。用具体表演：下颌绷紧、笑容收住、拇指停在屏幕上、呼吸卡住、眼眶发红但没落泪、声音压低。
10. **动作戏**：出现追逐/推搡/拳脚/械斗/摔跌/救援时，必做 `references/action-direction.md`——五段拆解、相位稳定点切 Block、真实物理、伤势连续性。仿真人线动作先看路径清不清，再谈冲击力。

### 台词规则（S/A/B/C）

- 中文台词短促、口语、可上字幕。
- 承载压力的称谓保留：妈、爸、奶奶、老公、老婆、沈总、林小姐、医生、警官。
- S 级台词完整保留；A 级压缩保核；B 级转动作/道具/反应；C 级仅因果不断时可删。
- 避免翻译腔与书面语。
- 不滥用吼叫、扇耳光、下跪、晕倒、大哭——除非源里有。
- **普通话为默认台词语言**；地域烟火气靠场景/地名/习俗/饮食/人物关系呈现，不靠方言语气词。音色锁定里的"轻微XX乡音"是角色属性，保留。
- 注意亲属称谓歧义：川渝"婆婆"=奶奶，普通话"婆婆"是婆媳的婆，跨地域题材必须用无歧义词。

### 镜头可见主体预算

- `👤 出场` 是本 Block 被摄影机真正拍到的角色主体清单，不是场景人物或资产库存。场景存在 ≠ 镜头可见。
- 竖屏优先 1–3 个镜头可见主体（生成稳定性建议值，不是硬上限）；群像可超，但画面描述必须写清前景/中景/后景与主要表演焦点。
- 纯氛围背景龙套不逐个写入出场行；一旦出现台词、关键动作、道具交互或推动剧情，升级为可见主体。
- 出场行只列角色主体；手机、钥匙、屏幕、伤口、家具不进。

### 时长估算（写 Block 时的内部手感）

新格式无单镜时长，用朗读估算控制节奏：

- 中文语速约 4.5 字/秒（争吵急促 6 字/秒，深情沉重 3.2 字/秒）；
- 有台词镜头 ≈ 字数 ÷ 语速 + 0.4s 留白（情绪镜头 +0.8s）；
- 纯动作/反应/空镜按导演手感给 2–4s；
- 单镜台词朗读 > 8s 必须拆镜或拆台词节拍；
- Block 总时长 ≤15s，目标 10–14s。

### 英文/海外项目附录

对白英文 + 海外机构/场景的项目走本线，但**不默认**：美式警探/法庭程序逻辑（除非题材本身是）、跨家庭层级的名字直呼、中文成语直译、派对文化套版。海外项目道具语汇换成其本地平台与文书（text thread、venmo、restraining order 等），关系压力换为其文化对应物。其余格式、闸门与编排完全一致。

## 模块 C：3D 横屏漫剧（原 manju-3d-storyboard 并入）

3D 漫剧项目走 V10 SOP，**不用**上面模块 A/B 的 2026-08-13 交付格式与机检脚本。执行顺序：

1. **阶段零已确认**渲染风格=3D 漫剧（3D 线默认横屏 16:9）。
2. **项目配置**（`references/3d-project-config.md`）：新剧必建——题材类型、风格包 ID/版本、
   精确 `视频整体基调` 锁定行、固定声线表、Q版OS 策略、禁用行、输出文件夹与命名。
   不复制旧项目的名字/声线/Q规则/风格锚。
3. **模块包**（`references/3d-module-packs.md`）：V10 通用底座常驻；视觉风格包与题材导演包
   项目初始化时匹配 2–3 候选让用户锁一个，之后只读不再选；题材不在登记册时按模板临场推导
   并报用户确认；特殊机制（Q版内心OS/系统UI/兽语）用户确认才启用。
4. **主流程**（`references/3d-v10-sop.md`）：源边界→项目配置→模块调用→剧情提纯→
   导演判断→空间台账→Block skeleton→相邻 Block 审→终稿→四道审计。只拆不编；
   台词 S/A/B/C 分级；Block≤15s；10–15s Block 通常 3–5 镜。
5. **格式**（`references/3d-prompt-format.md`）：V10 Block 含 `镜头 X 持续时间: Ys【取景主体景别 + 主运镜】`、
   每镜恰好一行 `镜头角度：`、`画面描述：`、`声线/语气：` 行、每 Block 逐字复用的基调行与禁用行。
   集尾必写 `本集总时长`/`遗留信息`（最后一帧、悬念、集尾空间快照、下集触发点）/`继续？`。
6. **机检**：`python3 scripts/audit_3d_storyboards.py --root <分镜目录>`（可选 `--tone` 精确基调、
   `--allow-q-episodes`、`--required-dialogue` 必保台词）。
7. **通用铁律照旧**：参考图权威（正文禁服装描述）、禁止同上、@资产名、AI难度不删内容、
   横向空间左/中/右与战斗轴线可读、越轴有动机。
8. 相邻 Block 缝合与空间连续性思想与模块 A/B 一致（smooth-seam gate、end=N+1 start、
   集尾空间快照），3D 特有的判定细则见 3d-v10-sop.md 与 3d-prompt-format.md。

## 空间连续性合同（原 storyboard-spatial-continuity-core）

详细判定规则见 `references/spatial-state-contract.md`。要点：

- 空间是逐镜头应用变化、逐 Block 继承的状态，不是形容词。
- 层级：单集 → 场景 → Block → 镜头；Block 是完整生成组，禁止 G 组二次分组。
- `👤 出场` 与 `🧭 起始空间状态` 只列镜头可见角色主体；画外角色留在内部台账。
- 移动必须写 `从 A 到 B`；摄影机运动不改变人物位置。
- 左右/朝向/视线须有原文依据；拍摄需要的画侧分配登记为银幕约定。
- 连续场：后一 Block.startState = 前一 Block.endState；换场重建。
- 集尾快照：逐角色姿态/位置/持物/伤势/去向＋直续/跳跃判定。

## 校验脚本

模块 A/B（2026-08-13 格式）：

```bash
python3 scripts/check_storyboard.py <分镜文件或目录>
python3 scripts/check_spatial_continuity.py <分镜文件或目录>
```

模块 C（V10 格式）：

```bash
python3 scripts/audit_3d_storyboards.py --root <分镜目录> [--tone <精确基调行>] [--allow-q-episodes 1-10] [--required-dialogue <必保台词文件>]
```

check_storyboard 检查：Block 头、编号连续、≤15s、📍/👤/基调/🧭/故事标签/🚫 各一行、**字段顺序**（场景→出场→基调→空间状态→故事→音频→🚫）、🎬镜头行格式（≥3段/取景主体/景别标准词/编号连续）、旧格式残留、服装词（穿着语境）、【音频规范】三要素。

audit_3d_storyboards 检查：V10 文件头七项、单镜时长与角度行、基调/禁用行逐字一次、镜头密度、
抽象词/泛称扫描、Q版合规、声线格式、集尾标记、必保台词核对。

脚本**不检查**：运镜词合法性（语汇开放，语义层审）、源忠实、语义连续、节奏真实性、主体-描述一致、
横屏构图/轴线质量（按 landscape-cinema-language.md 第七节自查）——这些靠阶段四的语义审查。

单测：`python3 scripts/test_check_storyboard.py`、`python3 scripts/test_check_spatial_continuity.py`、
`python3 scripts/test_audit_3d_storyboards.py`。
