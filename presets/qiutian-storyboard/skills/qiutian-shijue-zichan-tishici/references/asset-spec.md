## 事实源与归并

### 角色

输入含 `plot-map.md` 或角色索引时，先消费角色卡的别名/改名字段：

- `旧名→新名（EP-XX起）`：同一角色改名，资产名使用当前有效名，旧名写入「别名」。
- `某名（仅台词）`：台词称呼写入「别名」，不建新卡。
- `某名（禁）`：禁止作为资产名。

没有台账时才从剧本自行归并。职位称呼、亲属称呼和昵称不自动等于新角色。

### 道具

先读 `progress.md` 或同类文件中的道具/信物台账。台账别名并入同一道具卡，禁止一物多卡。外观相似但身份不同的物件分别建卡，并在「说明」写清关系。

### 场景

场景名优先锚定场次头地点原文：

- 地点名 ≤12 汉字时逐字使用，不自行改写。
- 地点名 >12 汉字时取可辨识主体缩形至 ≤12 汉字，并把场次头全名写入「别名」。
- 同一地点的不同局部只有在会被独立、重复引用时才拆卡。

## 七类资产

### 1. 角色

资产化对象：主要角色、有台词或关键表演的人、需跨镜头保持外貌一致的人。

以下情况必须建立独立角色卡，generic 群像卡只承担背景层：

- 同一人物标签跨集出现且承担独立对白。
- 剧本明确写“前景固定、锁脸、锁服色、延续上一场造型”。
- 具名甲/乙、长老、弟子等在连续场次中分别说话，画面需要观众区分。
- 一集承担关键情绪表演、后续集又以远景、回忆、婚礼等方式回返，需要同一外貌。

一次性说话路人可以由下游 inline；但源覆盖审计必须报出并在交付报告注明不入库理由。群像卡只覆盖 generic 背景层，每位成员具有清晰、完整、自然差异化的人脸，同时保持 generic 身份；它不能充当具名说话人的定妆图。原著明确蒙面、遮脸或无脸时，按证据呈现并在「说明」登记来源。

提示词可包含：

- 设定性别、当前外观呈现、呈现性质、年龄、身份、职业和地域气质。
- 脸型、骨相、五官、发型、身形、皮肤质感与生活痕迹。
- 1–2 个核心视觉记忆点。
- 服装和随身饰品。
- 稳定情绪气质，但不写动作段或夸张瞬时表情。

可见角色必须填写并写入提示词正文：

```text
设定性别：男 / 女 / 非二元 / 无性别 / 剧情刻意未明示
外观呈现：男性 / 女性 / 中性
呈现性质：本貌 / 日常穿着 / 身份伪装 / 舞台扮装
颜值定位：主演级惊艳 / 高辨识度耐看 / 清秀亲和 / 朴素真实 / 粗粝角色脸 / 其它有依据的明确定位
特殊标志：无 / 原文明确的花钿、痣、疤痕、胎记、异瞳、残缺或其它身份标记
```

- `设定性别` 记录用户或文本给出的角色设定，不等于服装、声线或模型对身体的猜测。
- `外观呈现` 记录当前画面的第一视觉身份；`呈现性质` 说明这是本貌、日常穿着、身份伪装还是舞台扮装。
- `特殊标志` 逐项记录当前状态必须可见的原文身份标记；没有写 `无`。非 `无` 项必须逐项进入文生图正文，不能被通用美貌词、妆容或发型遮掉。
- 女扮男装=`女＋男性＋身份伪装`；男扮女装冒充女性=`男＋女性＋身份伪装`；男性日常女装=`男＋女性或中性＋日常穿着`。不得只写“男装/女装”让图片模型自行决定角色性别。
- 文本确实刻意隐藏性别时使用 `剧情刻意未明示＋中性`，并在「说明」写证据。文生图正文写成“剧情保留性别悬念的中性人物”，同时完整、清晰呈现人脸。普通缺信息不能借此绕过核对；先查事实源，仍不明且性别影响出图时向用户确认。

### 脸部审美与美术补足

所有可见人形资产都呈现人脸。角色与 Q版小人使用完整清晰的正脸或三分之二侧脸；群像中的 3–6 人逐一具备完整、清晰、自然差异化的面孔。原著明确蒙面、遮脸或无脸时按原著呈现，并在「说明」登记剧本证据。

脸部使用最小充分结构，不再强制穷举五官：

1. 审美簇：用一个协调的整体意象规定审美方向，例如“清冷明艳的东方国漫女主形象”“温润端方的青年公子形象”。
2. 识别锚点：普通角色至少 1 个，主要角色通常 1–2 个；优先选择面部轮廓、眼形/眼尾、眉眼关系、年龄感或其它能区分角色的局部。
3. 特殊标志：原文明确的朱砂痣、花钿、疤痕、胎记、异瞳、残缺和年龄痕迹全部保留，不占识别锚点预算。
4. 呈现条件：重要角色可补“正面平视、自然舒展的人像透视、面部转折柔和、高光克制”等影响成片颜值但不改变身份的条件。

“绝美、漂亮、帅气、五官精致”只能作为颜值结论，不能替代识别锚点。鼻梁、鼻尖、唇峰、颧骨、额头和肤质等微结构只在原文明确、剧情需要或确实承担差异化时写入；没有必要时交给图片模型的整体审美先验。主要角色同时堆叠四类以上脸部微结构时先压缩，避免生成标准化娃娃脸、网红脸或塑料建模感。

不同主要角色不得复制同一段审美簇和识别锚点。核心记忆点和原文特殊标志优先于通用审美。

原文未给脸部结构时：

- 用户已明确整体审美、要求人物好看或授权美术设计：允许补足不改变身份与剧情的审美簇和少量识别锚点，在「说明」标 `美术补足：脸部识别锚点`。
- 用户未授权且美术补足会改变角色理解：先询问，不擅自把普通、粗粝、病弱或年长角色全部明星化。
- 美术补足不得替换、移动或删去原文明确的朱砂痣、花钿、疤痕、胎记、异瞳、残缺和年龄痕迹。

### 服装设计方向与性格外化

服装提示规定设计语言，最终选定的定妆图锁定具体款式。

原文明确写出婚服、校服、宗门服、制服、盔甲、孝服、舞台服等类别，或具体服装承担剧情识别时，保留原文事实。原文没有锁定具体款式时，不虚构完整单品清单，按以下顺序建立方向：

1. 身份与场合：时代、职业、阶层、组织、日常/正式/行动/伪装等语境。
2. 外显性格：角色第一眼给人的秩序感、亲和感、锋利感、张扬度或防御感。
3. 内在张力：外柔内韧、表面克制内里叛逆、身份低调能力强势等人物矛盾。
4. 视觉翻译：从轮廓、色彩关系、材质对比、结构手法、装饰密度中选择 2–4 项。
5. 固定记忆点：只保留 1–2 个有证据或经授权的饰品、纹样、识别色或结构特征。

职业只决定服装语境，性格决定设计语言，人物矛盾决定结构变化，记忆点决定唯一性。例如“设计师”不能只写“高级极简”，应写清她的克制、锋芒或实验性如何表现为轮廓秩序、材质对比和结构巧思。

服装段使用 `服装设计方向：` 开头，并满足：

- 不使用“长裤或半身裙、任选、可搭配、二选一”等不确定选项。
- 不在原文无依据时穷举领型、袖型、扣件、裙长、鞋型和每件单品。
- 同一张角色卡的头部特写与三视图保持同一套完整服装、相同妆发和相同饰品。
- 素戒、花钿、项链等随身标志只佩戴在角色身上，不拆成独立产品陈列。
- 女扮男装、男扮女装和其它身份伪装先服从 `外观呈现＋呈现性质`，再用轮廓、结构和装饰密度完成伪装；服装不能反向改写设定性别。

提示词不得包含：

- 房间、街道、店铺、车辆、桌椅等场景。
- 职业道具、手边物、锅具、屏幕、雨伞、手电等外部物。
- 雨夜、霓虹街景、街灯等场景氛围。
- 机位、运镜、动作过程。

版式：16:9，右侧头部清晰正面特写约占画面 40%，面部为第一视觉重点；左侧全身三视图（正/侧/背），中性全局照明，纯白无缝背景，仅呈现角色本体、服装与随身饰品。

### 2. 场景

资产化对象：主要故事空间、跨镜头/跨集重复地点、决定美术风格或空间叙事的局部。

先建立场次头闭合表：

```text
原场次头地点｜物理空间身份｜规范 @场景名｜别名｜出现集/时段｜合并或拆分依据
```

- 每个重复场次头地点必须精确命中一个规范名或别名。
- 同一物理空间因机构更名、前后缀扩写、旧称/新称变化而换名时，合并到同一卡的别名和出现集；不要复制成多套空间。
- 不同物理空间即使共享“王府、客栈、庭院”等词也不得模糊归并。
- 禁止用 `A.includes(B)` 一类模糊包含关系替代身份判断；精确别名未登记就视为覆盖缺口。

提示词必须包含：

- 时间桶、天气（只有成为稳定识别点时）、地点。
- 空间结构和可见动线。
- 光源位置与色温；日夜对不得把这些写死为单一时段。
- 固定陈设、材质、年代感、生活痕迹。
- 1–2 个固定视觉符号。
- `无人空镜场景设定图，仅呈现空间结构、固定陈设和环境质感` 的正向约束。

固定陈设和视觉符号必须满足至少一项：

1. 能回指剧本场次中的可见证据。
2. 用户已授权美术补足，且卡内说明标 `美术补足：场景结构/固定视觉符号`。

地点名只用于身份定位，不能直接充当陈设证据。不得因“江阳、江府、江南”含“江”就加入水面，也不得因名称含单个“宫、山、阁”就套入未经核对的固定结构。自动分类只允许完整词或经人工审阅的词典匹配。

可以写正面全景设定图、俯视结构设定图等资产构图，但不得写摄影机运动或分镜执行。

### 3. 道具

资产化对象：剧情关键物、反复触碰/观看的物件、需近景一致的物件。

提示词必须包含：

- 尺寸与比例参照。
- 材质、形状、颜色、基础磨损和使用痕迹。
- 剧情识别点；文字内容没有明确证据时使用不可辨或抽象排布。
- `白底或中性背景，仅呈现单一道具`。

不得写人物正在使用、完整场景、多人互动、镜头或运镜。场景风格词只有当它表现为道具自身的雨水、泥点、烧痕等物理痕迹时才允许。

### 4. 群像

跨集反复出现的 generic 群体必须建卡，例如员工群、弟子群、士兵方阵、酒客群。一次性路人或龙套由下游 inline 处理，不建库卡。

规则：

- 类型写 `群像`，名称建议以“群像”收尾。
- 3–6 人 generic 组合，服饰制式和身份特征统一。
- 明确写男性群像、女性群像、男女混合群像或中性人形群像；不得省略性别构成让模型随机分配。
- 每个人都有完整、清晰、自然差异化的人脸，同时保持 generic 身份并与具名角色区分；纯白或中性背景。原著明确蒙面、遮脸或无脸时按证据呈现，并在「说明」登记来源。
- 不写具名主角或剧情动作段。
- 默认不配音色；反复出现的齐呼/应和可登记 `{群像名}群声音色=（…）`。
- 状态化规则同角色，例如 `@士兵群像_战损`。

群像数为 0 的唯一合法条件：全剧排查确认不存在跨集复用 generic 群体，并在交付报告给出结论。

### 5. 生物

对象：有戏份或需跨镜头一致的动物、灵兽、坐骑、宠物、妖兽本体。

提示词包含：

- 物种、体型比例。
- 头部结构、眼/耳/角/口鼻。
- 毛皮、鳞甲或羽毛的颜色分区与风格化质感。
- 1–2 个核心记忆点。
- 稳定姿态气质，不写动作段。
- 属于生物本体的固定佩饰、鞍具、项圈。

版式同角色：16:9，右侧头部特写，左侧全身三视图，纯白无缝背景，仅呈现生物本体与固定佩饰。会说话或有兽语对白时配音色；纯叫声不配。

### 6. 不可见声音角色

对象：门内人、电话声、只闻其声的回忆对象、旁白、人格化系统音、器灵、识海传音者、AI 音。纯提示音效不建卡。

不得脑补正面形象。卡内文生图块说明不输出人物设定图，只使用剧本明确存在的来电界面、门缝、文字、光线或其它声音标记暗示其存在。必须配音色；后续真正出镜时升级为角色卡，原音色逐字保留。

### 7. 3D Q版小人

只用于 3D漫管线，且主角存在下游需要承载的长内心 OS，或用户点名需要。每位 POV 主角一张，配角不建。

- 名称固定 `@{角色}·Q版小人`；`·` 不得换成 `_`。
- 16:9，3D Q版 chibi，纯白背景，2–3 头身。
- 左侧 4–6 种常用表情，右侧同一小人全身正面立绘。
- 填写与本体一致的设定性别、外观呈现、呈现性质、颜值定位和特殊标志；继承本体发色、发型、性格化服装设计方向、脸部审美簇、识别锚点和核心记忆点，只做 chibi 化。
- 「说明」必须含 `全片统一造型，不随本体状态切换`；不拆多状态。
- 不单列音色；口播音色由下游统一约定。

## 多状态

### 触发门槛

先判断是否需要资产化，再判断是否状态化。只有同时满足以下条件才拆状态：

1. 剧本有明确可见变化。
2. 变化会影响静态设定图的视觉识别。
3. 后续镜头需要稳定复用该差异。

动作、表情、站位、奔跑、镜头远近、运镜、剪辑节奏和一次性光影变化不触发状态。视觉差异不足的疲惫/虚弱/崩溃等合并。

建议上限：单一角色 1–4 个状态、场景 1–5 个、道具 1–4 个。超限时先合并相近状态，服装较多的长篇主角可例外，但必须用场合语义和并行组合登记收敛。

### 完整卡与锚点

多状态资产不设 `@基础名` 总卡。每个状态卡包含完整类型、元信息、提示词和所需音色。

- 角色基础锚点：设定性别、年龄、颜值定位、脸部审美簇、1–2 个识别锚点、当前状态特殊标志、基础发型、身形、身份气质、核心记忆点，以及跨状态稳定时的服装设计 DNA。
- 场景基础锚点：地点、空间结构、动线、固定陈设、材质年代感、核心视觉符号。
- 道具基础锚点：尺寸比例、材质、形状、颜色、基础磨损、核心识别符号。

同一资产的基础锚点段逐字相同。状态段只写变化变量。年龄变体可以在状态段改变年龄，以及确受年龄影响的骨相幼态、发长和皮肤，其余锚点仍同文。禁止写“保留 @xxx”式跨卡引用。

### 角色状态维度

角色状态时间线维度六选一：`形态 / 体态 / 服装 / 伤势 / 身份呈现 / 特殊`。

可变项：年龄、服装、伤痕、污损、妆发、体态、整洁程度、外观呈现、呈现性质、当前可见特殊标志和长期情绪气质。设定性别、颜值定位、脸部审美簇、有证据的同脸识别锚点和核心记忆点保持稳定。

女扮男装、男扮女装、解除伪装或舞台反串改变画面第一视觉身份时使用 `身份呈现`；只有服装变化、外观身份不变时仍使用 `服装`。身份揭晓但静态外观未改变时不拆状态。

### 场景日夜

- 同一基础场景同时出现日和夜才拆一对。
- 清晨、正午、黄昏归入日；入夜、深夜归入夜。
- 两条提示词只替换句首 `白天` / `夜晚`，其余逐字相同。
- 母版本身不得含互斥时段词：白天卡不残留夜色、红月、月光、星空、夜幕；夜晚卡不残留烈日、正午、晨光、朝阳、夕阳。
- 现实层、回忆层、幻境层、极境层等互斥世界层不共用同一母版。只有剧本明确要求同屏叠合时可同卡，并在说明写出切换场次和叠合证据。
- 光源、色温、气氛写成不锁死时段的表述。
- 日夜只作用于基础场景，不与破败、焚毁、回忆等状态相乘。
- 只出现单一时段时保留基础名，不添加 `_日` 或 `_夜`。
- `全局实体索引` 给出强制建议名且没有列出 `_日/_夜` 时，逐字保留建议名并使用时段中立母版；卡内说明登记索引锁名，具体时段由下游场次头控制。

### 道具状态

可拆：完整/破损/烧毁/沾血、合上/打开、空白页/关键页、隐藏/显露、编号文字或关键标记变化。只改变开合、损坏、污染、文字内容、显露程度或关键标记；不写人物动作和场景。

### 状态命名

使用 `@资产名_状态词`。自主命名时状态词优先 2–6 个汉字，只写一个视觉状态；`全局实体索引` 给出的建议名逐字保留，其中复合状态名可含第二个 `_`。`·` 仅用于 Q版小人。

### 状态时间线

跨集项目每个状态一行：

```text
| @资产名_状态词 | 维度 | 生效区间 | 切换锚（切换点/剧情依据） |
```

生效集使用逐集事实汇总后的精确集合：连续段写 `EP-A–EP-B`，单集写 `EP-A`，离散段以顿号连接，例如 `EP-01、EP-05–EP-07、EP-12`。只有确有开放式持续证据且尚未完成全量逐集扫描时才暂用 `EP-A 起`；全量建库、覆盖重建和终版收口必须展开为实际集号集合。集内生效由切换锚指定。

状态卡的 `出现集` 与状态时间线的生效集逐字共用同一精确集合。实体总出现集只作为发现范围，不得回填到各状态卡；同一状态中途被其它状态替代后再次出现时保留离散段，不得用首尾集构造虚假连续区间。

同一角色同维度区间不得含糊重叠；场合交替必须有统一口径。跨维度重叠正常，但必须紧跟总表登记并行组合：

```text
| 重叠区间 | 角色 | 下游统一引用口径 |
```

统一口径由主状态卡、体态/持物道具卡和必要文字锚组成，不建立组合卡。

## 命名与元信息

### 名称

- `@资产名` 建议不超过 8 个汉字，复杂空间不超过 12 个。
- 名称表达身份，不塞完整描述。
- 全库同一资产保持同名；一次性物件不加 @。
- 可引用清单只列实际存在的卡；多状态基础名没有总卡，因此不得列入。

### 元信息

所有卡都有五行通用元信息：

```text
使用状态：有效 / 已废弃
替代资产：无 / @有效资产名 / 多个 @有效资产名 / 逐镜内联
别名：其它称呼、俗称、历史称谓；无则写「无」。
出现集：集号与场合；状态卡只写该状态逐集实际出现的精确集合，不继承实体总出现范围。
说明：身份一致性、历史形态、绑定关系、状态证据或跨集要点；无则写「无」。
```

五行是台账，不写进文生图正文。有效资产写 `使用状态：有效`、`替代资产：无`。旧版兼容卡不得删除，改写为 `使用状态：已废弃`；有单一替代时写 `替代资产：@...`，按时段/场合切换时可列多个有效 @，没有库级替代卡时写 `逐镜内联`。已废弃卡不得进入可引用清单、状态时间线或新出图文件名表。多状态卡的身份级别名一致，说明包含共享身份提示和该状态证据。

可见角色和 3D Q版小人在 `类型：` 后、通用三行前增加五行：

```text
设定性别：男 / 女 / 非二元 / 无性别 / 剧情刻意未明示
外观呈现：男性 / 女性 / 中性
呈现性质：本貌 / 日常穿着 / 身份伪装 / 舞台扮装
颜值定位：明确的角色审美层级与脸部气质
特殊标志：无 / 当前状态可见的原文身份标记，多个用顿号分隔
```

同一角色多状态的 `设定性别`、`颜值定位` 逐字一致；`外观呈现`、`呈现性质` 只有在 `身份呈现` 状态有证据时才改变；`特殊标志` 按当前状态实际可见内容填写。五行既是可机检身份台账，也必须在文生图正文中转写为自然语言，不能只留在元信息。

## 角色音色

唯一 schema：

```text
角色名音色=（【性别+年龄】嗓音演绎，音色【质感词】，音调【高/中/低】，【口音或特殊处理】。）
```

四槽分别是：

1. 性别 + 年龄段/身份，以“嗓音演绎”收尾。
2. 音色质感。
3. 偏高/偏中/偏低。
4. 普通话、方言、气声、沙哑、童声、电子处理等；无特殊写“标准普通话”。

要求：

- 与性别、年龄、职业和气场一致。
- 一经设定全片锁定。
- 同一角色各状态卡照抄同一基础音色。
- 幼年/老年等确实改变嗓音时可用 `{角色名}{变体}音色`；基础和变体都汇入音色表。
- 音色不写进文生图正文。

## 库级登记表

### 技能特效

打斗、法术或重复技能题材必出，非文生图资产、不占 @ 清单：

```text
{技能名}特效=（颜色{主色/辅色}，形态{剑气/光束/符文等}，粒子光效{拖影/碎光等}，来源{掌心/剑尖/枪口等}，余波{烟尘/残粒/地裂等}，等级递进{体量单向递增说明}。）
```

覆盖具名功法/招式和跨集通用特效；一次性杂兵攻击不登记。

### 可引用清单

每行必须含类型：

```text
@资产名（角色）
@资产名_状态词（场景）
@道具名（道具）
```

类型只允许：角色、场景、道具、群像、生物、不可见声音角色、3D Q版小人。

### 图片文件名

文件名等于资产名去掉 `@` 后加 `.png`。不可见声音角色不出图，不列入图片文件名对照表。多状态逐卡列出，不列基础名。

## 资产化判断

必须资产化：跨镜头/跨集复用、影响剧情识别、影响固定美术、关键近景一致性。可不资产化：一次性装饰、一次性路人、只在动作或镜头中成立的对象。

`comic-adapt-fidelity` 全季严格联动时，上游 READY 分集已经完成本节判断。直接采用标准 JSON 的 `candidate_cards` 作为唯一建卡集合，跳过本节后续的二次源覆盖发现；本节后续规则继续用于独立建库、旧 comic-adapt 回退和源覆盖审计模式。

“跨集复用”同时包括同一人物以旧称、身份称呼、远景标注或前后缀扩写再次出现。完成库后必须重新扫描全部说话人、出场人物和场次头；重复标签未命中资产名/别名视为漏卡或别名断链，不得仅凭人工印象宣称已覆盖。

源覆盖不得只判断“名称是否出现”，还要核对映射类型：

- 甲/乙/丙/丁、序数长老等可独立辨识标签有独立对白时，只映射到群像即为漏卡。
- 前景锁定人物、跨集独立说话人只映射到 generic 群像即为漏卡。
- 单集人物若有 4 句以上对白，或至少跨 2 场且有 2 句对白，必须建立角色卡，或在库内 `资产化决策台账` 登记 `逐镜内联/不资产化` 及可复核依据。
- 主角或主要人物的幼年、童年、具体年龄变体属于身份连续性状态；剧本出现年龄变体标签时必须有对应年龄状态卡。

群像人数必须在提示词中明确为 3–6 名。群像别名不得收录甲乙丙丁、序数长老等可独立辨识人物；两名互不共同出现的路人不能为了复用拼成群像。

状态词必须表达静态可见差异。`历史重复、兼容、废弃、旧版、修订、占位` 等维护语义不得作为有效状态词，只能通过 `使用状态/替代资产` 保留版本历史。

高强度单集人物的机器可读决策表使用：

```text
| 源标签 | 处理结果 | 目标/下游口径 | 依据 |
| 人物标签 | 角色卡/群像卡/逐镜内联/不资产化 | @资产名/逐镜描述 | 场次与连续性判断 |
```

不要为了凑齐类别虚构资产；但不能以篇幅为由漏掉真实存在的主要角色、主要空间、关键道具、常驻画外声和跨集群像。
