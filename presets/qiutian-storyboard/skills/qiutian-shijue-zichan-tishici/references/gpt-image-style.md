# GPT 图片模型适配规则

写任何最终文生图提示词前完整读取本文件。内部自检可以使用否定判断，交给图片模型的正文优先写正向目标。

## 1. 正向约束

优先使用：

```text
纯白无缝背景，仅呈现角色本体、服装与随身饰品
无人空镜场景，仅呈现空间结构、固定陈设和环境质感
白底或中性背景，仅呈现单一道具
纯白无缝背景，仅呈现生物本体与固定佩饰
```

避免在最终提示词中堆叠“不要、禁止、无、非、NOT、negative prompt”。特别不要写 `NOT 真人实拍/photoreal`；直接写目标渲染风格。

## 2. 避免过锐与堆料

禁用或尽量不用：

```text
精细、复杂、繁复、浓郁、HDR、高细节、8K、超高清、锐利、ultra sharp、hyper-detailed、intricate、HDR photography
```

替换为：

```text
清晰且边缘柔和，柔和边缘过渡，克制细节，大色块优先，材质语言统一，干净通透，必要结构细节保留
```

## 3. 风格尾缀

|:--|:--|:--|:--|
| 写实类 | 真实皮肤质感，自然肤色不均，毛孔克制可见，头发有真实重量感和自然分股，眼睛有湿润真实反光，柔焦边缘，胶片柔光，克制细节 | 柔和边缘过渡，克制细节，大色块优先，材质语言统一，空间层级清楚，单一视觉焦点，电影级柔光，画面干净通透 | 材质统一干净，边缘柔和但形体清楚，保留必要结构细节，弱化碎纹理 |
| 3DCG 国漫渲染 | 面部转折柔和自然，高光克制，肤质细腻并保留自然起伏，材质统一，干净建模，次表面散射克制，光影分明 | 材质统一，干净建模，空间层级清楚，光影分明 | 材质统一干净，边缘柔和但形体清楚，保留必要结构细节，弱化碎纹理 |

## 4. 性别、外观身份与扮装

可见角色提示词按以下顺序写：`年龄＋设定性别 → 当前外观呈现 → 呈现性质 → 颜值定位 → 脸部审美簇与识别锚点 → 特殊标志 → 身份气质/发型/身形 → 服装设计方向`。音色里的性别不算视觉声明。

正向写法：

```text
十八岁女性角色，当前为女性外观呈现，属于本貌
十八岁女性角色，当前以清秀少年男性身份呈现，属于身份伪装，男式束发与少年男装轮廓
二十五岁男性角色，当前为女性化外观呈现，属于日常穿着，女性化妆发与服饰造型，保持同一男性角色的面部骨相
二十五岁男性角色，当前以女性身份呈现，属于身份伪装，画面第一识别为年轻女性，保持同一男性角色的面部身份锚点
```

当设定性别与外观呈现不同，正文同时写出两层和呈现性质；不要只写“男装”“女装”或只写画面性别。剧情刻意未明示时使用 `外观呈现：中性`，正文写“剧情保留性别悬念的中性人物，完整、清晰呈现面孔”，并保留文本给出的全部体貌事实。

## 5. 脸部审美、自然呈现与差异化

采用“审美簇＋1–2 个识别锚点＋特殊标志”的最小充分结构：

```text
清冷明艳的东方国漫女主形象，面部轮廓清秀利落，眼尾轻微上扬；眉心固定一枚朱砂花钿
温润端方的青年公子形象，面部线条舒展，眉眼沉静；左眼下保留一粒浅痣
```

不要把额头、颧骨、下颌、眉形、眼裂、鼻根、鼻尖、唇峰和肤质全部写成同等优先级。没有剧情或差异化作用的微结构交给模型的整体审美先验；同一角色若同时出现四类以上脸部微结构，先删除不能承担身份识别的部分。

重要角色补充自然呈现条件：

```text
正面平视，自然舒展的人像透视，五官比例协调，面部转折柔和自然，高光克制
```

3DCG 国漫不混入真人毛孔、红血丝和胶片颗粒；使用“肤质细腻并保留自然起伏”降低塑料感。写实人物可保留克制毛孔和自然肤色不均。

每个主要角色选择不同的审美簇和识别锚点。`特殊标志：` 非 `无` 时，逐项直接嵌入脸部段，例如“眉心一枚朱砂花钿”“左眼下浅色旧疤”；通用美貌词不能挤掉这些身份锚点。

群像提示词逐一约束 3–6 名成员的人脸：每个人都有完整、清晰、自然差异化的面孔，同时保持 generic 身份并与具名角色区分。原著明确蒙面、遮脸或无脸时，按证据改写为对应的正向画面描述，并在卡内说明登记来源。

重要角色设定图写：

```text
右侧头部清晰正面特写并约占画面 40%，面部为第一视觉重点
```

如需进一步提高成片颜值，先用同一脸部段生成候选定妆图，选定后再作为参考生成三视图；候选选择与图片参考属于出图执行，不改变资产库内身份事实。

身份一致性要求高且原著采用可见人脸时使用两阶段：

1. 先生成正面脸部候选，脸部占画面一半以上，正面、无遮挡、光线均匀。
2. 选定候选后，以该图锁定脸部身份，再生成“右侧头部特写＋左侧三视图”的正式资产图。

使用多张参考图时明确职责：“参考图 1 只锁定脸部身份、发型轮廓和年龄感；参考图 2 只锁定体态、服装方向和饰品；不得混合两张图的脸部特征。”

## 6. 性格驱动的服装设计方向

服装不写成具体采购清单，也不能只写“现代服饰、古装、简洁高级、华丽”。使用固定前缀：

```text
服装设计方向：{身份与场合}，从{外显性格＋内在张力}出发，采用{轮廓、色彩关系、材质对比、结构手法、装饰密度中的 2–4 项}，以{固定记忆点}形成唯一性
```

示例：

```text
服装设计方向：符合年轻服装设计师与隐秘品牌主理人的身份，从清冷克制、外柔内韧且极有主见的性格出发，形成第一眼安静克制、细看暗藏锋芒的个人设计语言；整体轮廓修长干净，低饱和冷色建立稳定秩序，垂顺材质与小面积挺括结构形成柔与韧的对比，隐藏式层叠、精确切线和轻微不对称体现审美控制力，细节少但每一处都有设计意图
```

保持以下边界：

- 原文明示的婚服、校服、宗门服、制服、盔甲等类别不得改写。
- 原文未锁定具体款式时，不穷举领型、袖型、扣件、裙长、鞋型和每件单品。
- 不写“长裤或裙装、任选、可搭配、二选一”等开放选项。
- 同一张资产图的头部特写和三视图保持同一套完整造型。
- 素戒、花钿、项链等标志饰品只佩戴在角色身上，不另设产品展示区。
- 提示词负责设计方向；选定的定妆图负责锁定具体款式。

## 7. 电影写实风格包

只有用户选择电影写实、真人写实、写实电影感、现实主义影像、胶片电影感或短片写实风格时，才可追加：

```text
胶片电影美术设定图质感，柔和对比度，黑位略微提亮，自然光与实用光源主导，高光自然晕染，浅景深柔光，自然胶片颗粒，呈现电影剧照般的克制影调、真实材质和柔和层次。
```

3D、2D、国漫、日系、赛博朋克、插画、动画、美漫、像素、黏土、定格动画、低多边形等风格不调用该包。

## 8. 不吸收的内容

以下内容属于分镜或视频提示词，不进入资产库：

- 动作中段、动态模糊、人物在场景中做什么。
- 特写/中景/全景等镜头叙事模板；资产设定图自己的三视图/头部特写版式除外。
- 双人对手戏、机位、运镜、剪辑节奏。
- 图生图重绘、二次精修模型和模型串联工作流。

## 9. 场景语义防污染

地点名不是陈设清单。固定结构、材质和视觉符号逐项取自剧本证据或已授权美术补足，不按单字命中批量套模板。

- `江阳` 是人名，不能因含“江”推导水面。
- `江府`、`江南城客栈`、`南江小城客栈`不因含“江”自动出现石岸、水纹。
- 白天/夜晚母版先删除红月、月光、烈日、晨光等互斥词，再只替换句首时间词。
- 现实、回忆、幻境、极境等世界层分别建状态或分别写卡；只有剧本明确同屏叠合才允许同时进入一张提示词，并在说明登记证据。
