V2 及以后紧跟风格设置输出：

```markdown
## 变更记录

- 新增：@资产名（依据）。
- 补充：@资产名 出现集/别名（依据）。
- 改名：@旧名 → @新名（依据/日期）。
- 废弃：@资产名（原因）。
```

废弃卡保留原卡名、原正文与原音色，卡内改为：

```text
使用状态：已废弃
替代资产：@有效资产名 / 多个 @有效资产名 / 逐镜内联
说明：已废弃；{原因}；新提示词按替代资产或逐镜内联口径处理。
```

废弃卡不进入可引用清单、状态时间线与图片文件名对照表。

````markdown

替代资产：无
设定性别：{同角色各状态逐字一致}
外观呈现：{当前状态}
呈现性质：{当前状态}
颜值定位：{同角色各状态逐字一致}
特殊标志：{当前状态可见的原文身份标记；无则写「无」}
别名：{身份级别名，各状态一致}
出现集：{只写该状态}
说明：@角色名 多状态之一；全片同一张脸锚点；{性别/呈现证据与该状态证据；脸部/服装美术补足声明}。

文生图提示词：

```text
比例 16:9，{视觉风格}，角色设定图；画面右侧为角色头部清晰正面特写并约占画面 40%，正面平视、自然舒展的人像透视，面部为第一视觉重点；画面左侧为同一角色全身三视图（正面/侧面/背面），全部视图保持同脸、同发型、同一套完整服装和相同饰品；中性全局照明，纯白无缝背景，所有饰品均佩戴在角色身上，清晰且边缘柔和；{基础锚点段——设定性别、年龄、颜值定位、脸部审美簇、1–2 个同脸识别锚点、同角色稳定记忆点，各状态逐字相同}；{状态段——当前外观呈现、呈现性质、当前可见特殊标志及其它有证据的状态变量}；服装设计方向：{当前场合＋外显性格＋内在张力＋2–4 个视觉维度＋固定记忆点；同场合状态逐字锁定}。{风格尾缀}。
```

音色行：

```text
{角色名}音色=（……。）
```
````

`@角色名_状态B` 结构完全相同；设定性别、颜值定位、基础锚点段和基础音色逐字复制，只替换有证据的外观呈现、呈现性质、当前可见特殊标志、服装场合及其它状态变量。

- 核对核心记忆点；头部特写与三视图为同一对象、同一发型、同一套服装和相同饰品。
- 核对设定性别、外观呈现、呈现性质和特殊标志；女扮男装、男扮女装、日常异性化穿着和舞台扮装不得混淆。
- 主要角色脸部验收“审美簇＋1–2 个识别锚点＋特殊标志”；不同主要角色不得复制同一张脸，也不得为求完整堆满五官微结构。
- 颜值定位只规定审美目标，不得抹除年龄、伤病、生活痕迹和原文特殊标志；脸部自然舒展，无过度磨皮或塑料建模感。
- 服装验收人物性格是否被外化，设计方向是否同时体现身份场合与内在张力；不得只剩职业标签或空泛“高级感”。
- 所有随身饰品佩戴在人物身上，不出现独立产品陈列；服装提示无“或、任选、可搭配”等不确定方案。
- 多状态先验锚点一致，再验只有登记变量发生变化。
- 角色/生物/群像为纯白或规定中性背景；群像中的每个人都有完整、清晰、自然差异化的面孔并保持 generic 身份；原著明确的蒙面、遮脸或无脸设定与说明证据一致。
- 场景采用无人空镜，空间结构与固定陈设符合卡片。
- 道具为白底/中性背景，剧情识别点清楚。
- Q版小人可识别为本体同一角色。
- 不合格图片优先重出该图；提示词本身有错才升版改库。
